# 시간과 일정 파일의 꼴

앱의 "시간과 일정" 화면에서 한 사람이 날마다 쓸 시간과 전시 밖 일정을 넣고 "내 것을 파일로 내보내기"를 누르면 이 꼴의 파일이 내려온다. 단톡방으로 건네면 나머지는 "받은 파일 불러오기"로 넣는다.

**이 레포는 공개다. 우리 일정표 · 시간 · 장소 목록을 여기에 적지 않는다.** 아래는 빈 예시다. 채운 파일은 폰과 단톡방에만 둔다.

```json
{
  "app": "ces-2027-myplan",
  "v": 1,
  "hours": [
    { "date": "YYYY-MM-DD", "from": "HH:MM", "to": "HH:MM" },
    { "date": "YYYY-MM-DD", "off": true }
  ],
  "events": [
    { "date": "YYYY-MM-DD", "from": "HH:MM", "to": "HH:MM", "name": "", "place": "" }
  ],
  "perStopMinutes": 30
}
```

| 칸 | 뜻 |
|---|---|
| `app` · `v` | 늘 `ces-2027-myplan` · `1`. 다르면 불러오지 않는다 |
| `hours` | 날마다 전시를 볼 시간. 적지 않은 날은 CES 공식 전시 시간을 쓴다. `off: true`는 그 날 전시를 보지 않는다는 뜻 |
| `events` | 전시 밖 일정. `name`은 꼭, `place`는 비워도 된다. 전시 기간 밖의 날짜도 된다 (공항 이동 같은 것) |
| `place` | 앱이 아는 곳의 한글 이름(예: 스피어 · 프리몬트 스트리트 · 룩소르, 또는 CES 장소 이름)을 적으면 그 주소로 구글맵을 연다. 다른 글이면 그 글로 구글맵에서 찾는다 |
| `perStopMinutes` | 한 곳에 쓰는 시간. 15 · 20 · 30 · 45 · 60 가운데 하나. 없어도 된다 |

불러올 때:

- 시간은 그 날짜의 것을 덮어쓴다.
- 일정은 같은 것(날짜 · 시작 · 이름이 같은 것)이 이미 있으면 건너뛴다.
- 꼴이 맞지 않는 줄은 빼고, 무엇을 뺐는지 화면에 알린다.
- 불러온 것은 그 폰에만 남는다.

읽고 쓰는 코드는 `web/days.js`의 `readFile` · `makeFile`이다.
