# 끝나면 비공개로

요구 R17이다. 날짜는 정하지 않았다 (`config/settings.json`의 `privateOn`, 안은 1/31). 2026-11-21에 이재엽이 "아직 정하지 않는다"고 했고, 다녀온 뒤(1/15 ~)에 다시 묻는다. 아래는 그날 하는 차례다. 하는 사람은 이재엽이다.

## 돌리기 전에 (남길 것)

- [ ] 네 태그 한 장이 내 노트(my-os)에 있다.
- [ ] 모은 일기 파일이 내 노트 쪽에 있다 (레포에는 없다).
- [ ] 구글 시트로 모았다면 Apps Script의 배포를 내렸다.
- [ ] 팀에게 "언제 페이지가 내려간다"고 알렸다. 각자 폰의 명함 · 관심 · 갈 곳 · 일기는 폰에 남지만, 페이지가 내려가면 새로 열거나 새 판을 받을 수 없다. 필요하면 그 전에 설정에서 갈 곳 목록과 일기를 파일로 내려받으라고 한다.
- [ ] 보드 묶음(`docs/board/board.single.html`)은 인터넷 없이 열리니 따로 둔다.

## 돌리는 차례

1. 레포 Settings → Pages → 게시를 끈다 (Unpublish).
2. 레포 Settings → General → Danger Zone → Change visibility → Private.
3. 주소(`https://gamercross.github.io/ces-2027/`)가 열리지 않는지 다른 브라우저로 본다.
4. 단톡방 안내 글에 적었던 주소를 지우거나 "내렸다"고 알린다.

## 돌린 뒤 달라지는 것

- 무료 요금제에서는 비공개 레포의 Pages를 쓸 수 없다. 페이지는 내려간다.
- 이미 홈 화면에 추가한 폰은 담아 둔 판으로 한동안 열린다. 지우려면 각자 홈 화면에서 지운다.
- 이슈 · PR · Actions 기록은 그대로 남고 이재엽만 본다.
- 다시 공개로 돌리면 Pages를 다시 켜야 한다.

## 정할 것

- 돌리는 날 (안: 1/31).
- 레포를 지우지 않고 비공개로만 두는 것이 맞는지 (요구는 "끝나면 비공개").
