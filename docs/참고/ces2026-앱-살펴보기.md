# CES 공식 앱 살펴보기

이재엽의 말(2026-11-22): "이미 있는 CES 2026 앱을 다운받아서 밑작업은 rea를 이용해서 … 디자인들도 준비하면서 전부 단계들을 준비해서 계속 작업".

- 이 문서는 **참고만** 한다. 공식 앱의 코드 · 그림 · 아이콘 · 로고 · 지도 그림 · 문구를 가져오지 않았다. 관찰은 우리 말로 적었고, 크기는 스토어 그림에서 눈금으로 잰 어림(±3)이다.
- 이미 있는 [공식앱_기준표.md](../공식앱_기준표.md)(기능 20줄)와 겹치는 것은 그 표를 고치고 여기서는 줄 번호로 잇는다. 새로 본 것은 기준표 2.3절에 더했다.
- 디자인 준비는 [단계별-디자인-준비.md](단계별-디자인-준비.md)에 있다.

## 1. 앱을 받으려 한 길과 결과 (2026-11-22)

| 순서 | 길 | 결과 |
|---|---|---|
| ① | 이 Mac의 `/Applications`에 이미 있나 | 없다 |
| ① | 이 Mac의 App Store(애플 계정으로 로그인됨)에서 "CES 2027"(번들 이름 `com.cta.ces`, 13.0.0, 11/10 갱신, 165MB) | 앱 페이지에 **"이 기기와 호환되지 않습니다"**가 떴다. 아이폰 · 아이패드용만 있고 이 Mac(애플 칩)에는 내려받을 수 없는 앱이다. "받기"는 누르지 않았다 |
| ② | 안드로이드 설치 파일(APK) 미러. 공식 Play 쪽에는 "CES 2027"이 있다(`com.cta.cestech`) | APKPure는 봇 차단(403), APKCombo · APKMirror에는 이 앱의 항목이 없다. 차단을 돌아가지 않았다 |
| ③ | 로그인 · 결제가 필요한가 | 앱을 쓰려면 CES 계정(등록 때 쓴 메일)으로 로그인해야 한다고 공식 안내가 말한다. 파일은 못 받아서 시험하지 않았다 |

그래서 **앱 파일은 받지 못했고**, rea의 파일 도구(`inspect_artifact` · `extract_artifact` · `binary_overview` · `inspect_asset_catalog` · `decode_interface_builder` · `list_strings` · `analyze_javascript_application` · `trace_application_feature`)는 쓸 대상이 없었다. 공개 웹과 스토어 자료를 아래처럼 읽었다.

- 저장소 밖 폴더 `~/Downloads/ces2026-app/`에 스토어 화면 그림 8장(아이폰 4 · 안드로이드 4, 같은 4화면), 스토어 소개 JSON · HTML, 공식 안내 페이지 HTML을 두었다. 저장소에 넣지 않았다.
- rea `inspect_web_page`로 공식 앱 안내 페이지(ces.tech)의 글 · 구조를 읽었다. 전시사 웹(exhibitors.ces.tech)은 내 조사용 브라우저에 **403 Forbidden**을 돌려줘서 돌아가지 않고 멈췄다.
- 주인(이재엽)이 아이폰 미러링으로 2026 공식 앱을 띄워 Aside로 살펴보는 중이다. **그 목록이 오면 7절 "주인이 실제 앱에서 본 것"으로 합친다**(지금은 비어 있다).

## 2. 본 범위와 못 본 범위

| 본 것 | 근거 | 믿는 정도 |
|---|---|---|
| 시작 화면 · 홈 · 일정 · 전시사 목록 네 화면의 모양 | 스토어에 올라온 홍보 화면 그림 4장(아이폰 · 안드로이드 같은 그림) | 홍보용이라 실제와 조금 다를 수 있다. 화면 속 이름 · 날짜는 견본이다 |
| 기능 목록(일정 · 즐겨찾기 · 지도 · 번역 · 연락처 교환 · AI 챗봇 · 교통 · 알림) | CES 공식 앱 안내 페이지 · App Store 소개 글 | 공식 말이다. 현장에서만 되는 것은 눌러 보지 않았다 |
| 지도(3D · 확대 · 파란 점 1 ~ 3m · 층 감지 · 부스 누르기) | 앱을 만든 회사 Eventbase의 안내 글(2026판 설명) | 회사의 말이다. 2027판에서 같다는 보장이 없다. 지도 화면 그림은 못 봤다 |
| 사이드 메뉴의 전시사 A–Z · 즐겨찾기 고정 | 같은 안내 글 | 메뉴를 열어 본 것이 아니다 |

| 못 본 것 | 까닭 |
|---|---|
| 앱 안의 지도 화면 · 사이드 메뉴 안 · 설정 화면 · 전시사 카드 · 내 일정 화면 · 명함(연락처) 화면 · 알림 화면 | 앱 파일을 못 받았고 스토어 그림이 네 화면뿐이다 |
| 글자 크기 설정 · 오프라인에서 되는 것 | 공식 글 어디에도 없다. **못 봄** |
| 앱 파일 속(코드 · 자료 · 암호화 부분) | 파일이 없다. 암호화를 풀려 하지 않았다 |
| rea가 가린 것 | `inspect_web_page`는 정책상 콘솔 · 저장소 열쇠 · 스크립트 소스 · 리소스 목록을 가렸고, 붙기 전의 네트워크 기록은 없다. 그 가려진 구간은 보지 못한 것으로 적는다 |

앱 안에서 찾은 키 · 토큰 · 비공개 주소는 쓰지 않았고 적지 않았다. 공식 안내 페이지에 분석 도구의 열쇠가 보였으나 문서에 옮기지 않았다.

## 3. 화면 지도 (공식 앱)

스토어 그림 4장과 안내 글로 그린 것이다. 점선은 글에서만 알고 화면은 못 본 것이다.

```
[시작 화면] 붉은 → 노란 판 + 큰 흰 문구 한 줄 (잠깐)
      ↓
[홈] ─ 머리: 왼쪽 위 메뉴(햄버거) · 오른쪽 위 검색
   │   인사 + "일정 보기" 큰 단추 하나
   │   오늘 날짜 · 바로 가기 둘(전시사 · 일정)
   │   "나에게 추천" 가로 카드 줄 + 전체 보기
   │
   ├─ [일정] 월 제목 · 뒤로 · 검색
   │     날짜 띠(요일 + 날짜 숫자, 4일) → 두 칸(일정 | 내 일정)
   │     칩 셋(거르기 · 추천 · 주요) → 날짜 묶음 띠
   │     줄: 때 · 제목 · 곳(건물, 층, 방) · "담음" 단추 · 알람 아이콘
   │
   ├─ [전시사] 큰 칸 목록: 전체 · LVCC · 베네시안 · ARIA · 코스모폴리탄 · 앙코르 …
   │
   ┆─ [사이드 메뉴] 전시사 A–Z · 즐겨찾기(전시사 · 연사) 고정 ··· 안은 못 봄
   ┆─ [지도] 3D · 확대 · 파란 점 · 부스 누르기 ··· 화면은 못 봄
   ┆─ [연락처 교환 · AI 챗봇 · 번역 · 교통 · 안내 자료] ··· 화면은 못 봄
```

- **길(탭 · 메뉴):** 화면 위의 메뉴(햄버거)와 검색이 홈 · 전시사에 같이 있고, 일정에서는 메뉴 자리에 뒤로가 온다. 안드로이드 그림은 화면 맨 아래(제스처 막대)까지 보이는데 **아래 탭이 없다**. 아이폰 그림은 아래가 잘려 있다. 앱 안 모든 화면이 그렇다고 단정하지 않고 "본 화면에는 없다"로 적는다.
- 우리 앱은 아래 탭 넷(지도 · 동선 · 일기 · 설정)이고 앱을 열면 지도다. 공식 앱은 홈이 있다.

| 일부 세션 실시간 번역 | 글 | **없음** | 12 |

## 5. 지도 자세함 견주기

공식 쪽은 **글 근거뿐**이다(지도 화면 그림은 못 봄). 우리 쪽은 코드 · 사진 · `작업.md`로 확인했다.

| 항목 | 공식 앱(글) | 우리 앱(2026-11-22) | 차이 · 배울 점 |
|---|---|---|---|
| 지도 종류 | 건물 안을 보여 주는 3D 지도(돌려 보기) | 2D 기본, 3D는 단추 하나로 불러옴(기둥 모양) | 공식은 층 · 방 모양까지 그린다고 한다. 우리는 홀 모양 + 부스 점 |
| 확대 단계 | "확대 단계를 고르는 조절"이 있다(단계 수는 못 봄) | **셋**: 캠퍼스(칸 너비 1300 이상) → 홀(520 ~ 1300) → 부스(520 아래) | 단계마다 글자가 달라진다(캠퍼스: 홀 이름 · 홀: 큰 회사 · 부스: 번호 + 이름) |
| 글자 | 못 봄 | 13px 아래로 안 줄이고 겹치면 숨김. 관심 · 동선 회사는 늘 보임 | 우리가 읽히는 기준을 숫자로 갖고 있다 |
| 층 | 여러 층을 감지하고 층 사이 이동도 안내 | **없음** | 우리 가장 큰 차이. 전시장은 홀별 한 층 짐작이다 |
| 내 위치 | 파란 점, 현장 장비로 1 ~ 3m(회사의 말) | GPS + 부스 번호. 홀 안은 어림 | 홀 안에서 우리 점이 몇 m 틀리는지는 실제 폰 시험이 남았다 |
| 길 찾기 | 실내 길 안내, 실내 · 실외 전환 | 같은 홀은 짐작 선 · 남은 거리 · 걸어서 몇 분(분당 70m) · 방향, 5초마다 위치 갱신, 30m 안이면 "도착". 다른 캠퍼스는 구글맵 + 셔틀 | 선이 짐작이라 숫자도 짐작이다 |
| 부스 정확도 | 공식 배치도 기반 | 번호로 짐작한 자리(정식 배치도 `validHalls`가 비어 있어 기다림) | 배치도가 열리면 자동 반영 길이 준비돼 있다 |
| 부스 누르기 | 회사 정보 · 사진 · 링크 · 길 | 카드: 이름 · 부스 · 홀 · 분야 · 자리 짐작 · 담기 · 동선에 넣기 · 길 안내 · 공식 링크. 사진은 링크 | 같은 한 번에 정보가 뜬다 |
| 검색 | 세션 · 장소 · 연사 · 전시사를 한 곳에서 | 회사 이름 · 분야 · 부스 번호 · 홀(번호 범위로 홀) | 세션은 동선 쪽에서 따로. 연사는 없다 |
| 오프라인 | **못 봄** | 한 번 열면 인터넷 없이 지도 · 동선 · 일기가 열린다 | 우리 쪽이 확실하다 |

## 6. 디자인 관찰 (공식 앱, 스토어 그림 4장)

수치는 그림에서 눈금으로 잰 어림(±3, 폰 가로 약 410dp 기준)이다. 홍보 그림이라 실제 앱과 다를 수 있다.

## 7. 주인이 실제 앱에서 본 것 (대기)

이재엽이 아이폰 미러링 + Aside로 2026 공식 앱을 살펴 정리하는 중이다(2026-11-22). 도착하면 이 절에 "본 것 · 우리 앱과 견줌"으로 합치고, 3 ~ 6절의 "못 봄" 줄(지도 화면 · 사이드 메뉴 · 설정 · 연락처 화면 · 글자 크기 · 오프라인)부터 채운다.

## 8. 우리 앱에 없는 큰 것 다섯

1. **부스 단위 실내 지도 + 층 + 파란 점 1 ~ 3m 길 안내** — 정식 배치도와 현장 장비가 있어야 한다. 배치도가 열리면 부스 자리는 반영되지만 층과 파란 점은 따로다.
2. **사람 잇기** — 서로 수락하는 연락처 교환 · 바뀌는 QR · 앱 안 연결. 서버가 있어야 한다.
3. **계정으로 일정 맞추기와 닫힌 앱의 알림** — 웹 일정과 맞추기 · 줄별 알람 푸시. 서버와 로그인이 있어야 한다.
4. **실시간 번역과 실시간 교통 대기** — 공식 앱의 서버 자료다(번역은 이재엽이 지웠다).
5. **AI 챗봇(목소리 · 여러 언어)과 사진 · 연사가 풍부한 전시사 정보** — 글을 지어내는 서버와 공식 자료 접근이 필요하다.

## 9. 주인이 정할 것

- 서버 없는 원칙을 그대로 둘지(위 2 · 3번은 서버 없이 못 한다). 이 문서는 **그대로 두는 쪽**을 권한다.
- 연사를 읽을지(기준표 2.1절에 남은 것).
- 일정 날짜 띠에 **1/5(화) 사전 일정**을 넣을지. 스토어 그림의 일정은 1/5부터 보인다.
- 설정에 **"이 폰의 내 자료 지우기"**(두 번 확인)를 넣을지, 글자 크기에 "폰 설정 따름" 단계를 둘지(권하지 않음).
- 화면 처음 한 화면의 설명 글 상한 60자를 정할지.
- 주인의 실제 앱 기능 목록이 오면 7절에 합친다.
