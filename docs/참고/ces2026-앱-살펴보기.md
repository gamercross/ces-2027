# CES 공식 앱 살펴보기

이재엽의 말(2026-11-22): "이미 있는 CES 2026 앱을 다운받아서 밑작업은 rea를 이용해서 … 디자인들도 준비하면서 전부 단계들을 준비해서 계속 작업".

- 이 문서는 **참고만** 한다. 공식 앱의 코드 · 그림 · 아이콘 · 로고 · 지도 그림 · 문구를 가져오지 않았다. 관찰은 우리 말로 적었고, 크기는 스토어 그림에서 눈금으로 잰 어림(±3)이다.
- 이미 있는 [공식앱_기준표.md](../공식앱_기준표.md)(기능 20줄)와 겹치는 것은 그 표를 고치고 여기서는 줄 번호로 잇는다. 새로 본 것은 기준표 2.3절에, 공식 웹 플래너에서 본 것은 2.4절에 더했다(7.6절).
- 디자인 준비는 [단계별-디자인-준비.md](단계별-디자인-준비.md)에 있다.

## 1. 앱을 받으려 한 길과 결과 (2026-11-22)

| 순서 | 길 | 결과 |
|---|---|---|
| ① | 이 Mac의 `/Applications`에 이미 있나 | 없다 |
| ① | 이 Mac의 App Store(애플 계정으로 로그인됨)에서 "CES 2027"(번들 이름 `com.cta.ces`, 13.0.0, 11/10 갱신, 165MB) | 앱 페이지에 **"이 기기와 호환되지 않습니다"**가 떴다. 아이폰 · 아이패드용만 있고 이 Mac(애플 칩)에는 내려받을 수 없는 앱이다. "받기"는 누르지 않았다 |
| ② | 안드로이드 설치 파일(APK) 미러. 공식 Play 쪽에는 "CES 2027"이 있다(`com.cta.cestech`) | APKPure는 봇 차단(403), APKCombo · APKMirror에는 이 앱의 항목이 없다. 차단을 돌아가지 않았다 |
| ③ | 로그인 · 결제가 필요한가 | 앱을 쓰려면 CES 계정(등록 때 쓴 메일)으로 로그인해야 한다고 공식 안내가 말한다. 파일은 못 받아서 시험하지 않았다 |

그래서 **앱 파일은 받지 못했고**, rea의 파일 도구(`inspect_artifact` · `extract_artifact` · `binary_overview` · `inspect_asset_catalog` · `decode_interface_builder` · `list_strings` · `analyze_javascript_application` · `trace_application_feature`)는 쓸 대상이 없었다. 공개 웹과 스토어 자료를 아래처럼 읽었다.

- 저장소 밖 폴더 `~/Downloads/ces2026-app/`에 스토어 화면 그림 8장(아이폰 4 · 안드로이드 4, 같은 4화면), 스토어 소개 JSON · HTML, 공식 안내 페이지 HTML을 두었다. 저장소에 넣지 않았다.
- rea `inspect_web_page`로 공식 앱 안내 페이지(ces.tech)의 글 · 구조를 읽었다. 전시사 웹(exhibitors.ces.tech)은 내 조사용 브라우저에 **403 Forbidden**을 돌려줘서 돌아가지 않고 멈췄다.
- 주인(이재엽)이 아이폰 미러링에 공식 앱을 띄워 주었고, 같은 날 저녁(폰 시계 19:45 ~ 19:52) 직접 눌러 넘기며 읽었다. 결과는 **7절**이다(앱 파일을 못 받은 것은 그대로).

## 2. 본 범위와 못 본 범위

| 본 것 | 근거 | 믿는 정도 |
|---|---|---|
| 시작 화면 · 홈 · 일정 · 전시사 목록 네 화면의 모양 | 스토어에 올라온 홍보 화면 그림 4장(아이폰 · 안드로이드 같은 그림) | 홍보용이라 실제와 조금 다를 수 있다. 화면 속 이름 · 날짜는 견본이다 |
| 기능 목록(일정 · 즐겨찾기 · 지도 · 번역 · 연락처 교환 · AI 챗봇 · 교통 · 알림) | CES 공식 앱 안내 페이지 · App Store 소개 글 | 공식 말이다. 현장에서만 되는 것은 눌러 보지 않았다 |
| 지도(3D · 확대 · 파란 점 1 ~ 3m · 층 감지 · 부스 누르기) | 앱을 만든 회사 Eventbase의 안내 글(2026판 설명) | 회사의 말이다. 2027판에서 같다는 보장이 없다. 지도 화면 그림은 못 봤다 |
| 사이드 메뉴의 전시사 A–Z · 즐겨찾기 고정 | 같은 안내 글 | 메뉴는 열어 봤다(일곱 줄, 3절). 메뉴에 A–Z 줄은 없고, A–Z는 전시사 · 연사 목록 오른쪽 색인으로 있다. 즐겨찾기 고정은 못 봤다(즐겨찾기가 비어 있다) |
| **실제 앱 약 30화면**: 내 프로필 · 설정 · 메모 · 즐겨찾기 · 홈 · 사이드 메뉴 · 전시사 목록 · 거르기 · 회사 카드 · 부스 · 일정(1/4 · 1/6) · 내 일정 · 세션 · 일정 거르기 · 내 CES 타일 · 알림 · 추천 · 연결 타일 · 연사 · 행사 정보 타일 · 앱 안내 · 검색 | 2026-11-22 저녁 아이폰 미러링으로 직접 열어 읽음(7절) | 가장 믿을 만하다. 로그인 없는 상태이고 행사 한 달 반 전이라 견본 자료가 섞여 있을 수 있다 |

| 못 본 것 | 까닭 |
|---|---|
| **지도 화면**(홀 · 부스 · 층 · 파란 점 · 확대 단계 · 부스 카드) | 로그인 없이 연 화면 어디에도 지도 화면이 없었다. 사이드 메뉴 · 홈 · 내 CES · 연결 · 행사 정보 · 검색 어디에도 지도 줄이 없고, 부스 · 세션의 핀 아이콘은 지도가 아닌 목록 화면으로 갔다. 로그인 뒤나 행사가 가까워지면 열리는지는 모른다 |
| 연락처 나누기(QR) · 명함 · 참가자 명단 · 추천 안 · 프로필 관리 | **로그인이 필요하다**(7.4). 눌러 보니 CES 계정 로그인 창이나 "로그인하세요" 안내가 떴다. 로그인 · 가입은 하지 않았다 |
| 오프라인에서 되는 것 | 네트워크를 끄는 일은 이 방에서 막혀 있어 시험하지 않았다. 행사 정보 타일은 웹 안내 페이지라 불러오는 동안 빙글 돈 것만 봤다 |
| 앱 파일 속(코드 · 자료 · 암호화 부분) | 파일이 없다. 암호화를 풀려 하지 않았다 |
| rea가 가린 것 | `inspect_web_page`는 정책상 콘솔 · 저장소 열쇠 · 스크립트 소스 · 리소스 목록을 가렸고, 붙기 전의 네트워크 기록은 없다. 그 가려진 구간은 보지 못한 것으로 적는다 |

앱 안에서 찾은 키 · 토큰 · 비공개 주소는 쓰지 않았고 적지 않았다. 공식 안내 페이지에 분석 도구의 열쇠가 보였으나 문서에 옮기지 않았다.

## 3. 화면 지도 (공식 앱)

2026-11-22 저녁 **실제 앱을 눌러 넘기며** 그린 것이다(로그인 없는 상태). 점선은 눌러 봤지만 로그인이 있어야 열리거나(로그인) 끝내 안 열려서(지도) 안을 못 본 것이다.

```
[환영 화면 4장] 큰 그림 + 글 + 큰 단추 "로그인" + 글자 단추 "나중에" (첫 장만 앞 일꾼이 봄)
      ↓ "나중에"
[홈(발견)] ─ 머리: 왼쪽 위 메뉴(햄버거) · 오른쪽 위 검색 (남색 대신 보라 판 위에 얹힘)
   │   위쪽 절반: 큰 제목 + 설명 두 줄 + 연두 "로그인" 단추 (로그인하면 인사로 바뀔 것)
   │   오늘 날짜 · 바로 가기 둘(전시사 · 일정)
   │
   ├─ [사이드 메뉴] 일곱 줄: 내 CES · 내 프로필(로그인 안 함 표시) · 발견(>) · 일정 · 연결 · 전시사 · 행사 정보
   │
   ├─ [내 CES] 큰 타일 여섯: 일정(맨 큰 것) · 즐겨찾기 | 알림 · 추천 · 프로필 관리 | 설정 · 연락처 연결
   │     ├ 일정 ··· 이 타일은 안 눌렀다(일정 화면의 "내 일정" 칸과 같은 것으로 보임)
   │     ├ 즐겨찾기 · 설정 ··· 내 프로필 쪽 같은 이름의 화면을 열어 봤다(아래)
   │     ├ 알림 = "메시지" 한 줄짜리 빈 화면
   │     ├ 추천 = 타일 셋(세션 · 전시사 · 참가자) ··· 전시사 추천을 열어 보니 로그인 필요
   │     ├ 프로필 관리 ··· 안 눌렀다
   │     └ 연락처 연결 ··· 로그인 필요(웹 로그인 창이 뜸)
   │
   ├─ [내 프로필] 로그인 권유 판 + 타일 셋: 메모(개수) · 설정 · 즐겨찾기
   │     ├ 메모 = 칸 셋(전시사 · 세션 · 참가자) + "모두 내보내기", 비었을 때 한 줄
   │     ├ 즐겨찾기 = 칸 넷(전시사 · 세션 · 연사 · 참가자), 비었을 때 하트 그림 + 한 줄
   │     └ 설정 = 세 묶음 항목 넷(알림 · 위치 알림 · 분석 · 행사 시간대)
   │
   ├─ [일정] 날짜 띠 여섯(월 1/4 ~ 토 1/9) → 두 칸(일정 | 내 일정) → 칩 둘(거르기 · 주요) → 보라 날짜 띠 → 줄
   │     줄: 때 · (유료 표시 · 대상 태그) · 제목 · 곳(건물, 층, 방) · "일정에 담기" 글자 단추 · 하트 · 알람
   │     ├ 세션 화면: 위 큰 판(그림 칸 + 제목 + 곳) → 때(+ 담기 · 하트 · 알람) → 곳(핀) → 추가 정보 → 연사 → 분류 → 설문 → 메모
   │     └ 거르기: 전체 화면 창(시간대 슬라이더 · 쉬운 거르기 · 분류 넷 · 큰 파란 단추)
   │
   ├─ [전시사] 칩 하나(거르기) + 줄 목록 + 오른쪽 A–Z 색인
   │     ├ 회사 카드: 머리 판 → 즐겨찾기 줄 → 상 · 세션 · 주소 · 위치(부스) · 더 알아보기 · 분류 · 메모
   │     ├ 부스 화면: 로고 + 이름 + "홀, 부스번호" → 주소 → 위치(하트 + 핀) → 그 자리의 전시사
   │     └ 핀 = **지도가 아니라** "그 자리에 있는 전시사 목록" 화면
   │
   ├─ [연결] 타일 다섯: 참가자 명단 · 추천 · 받은편지 · 연사 · 연락처 연결  ┄ 연사 목록만 로그인 없이 열림
   │
   ├─ [행사 정보] 타일 아홉(전시 시간 · 배지 · 등록 · 앱 소개 · 안전 · 교통 · 현장 서비스 · 링크드인 · 계정 · 앱 안내)
   │     └ 대부분 ces.tech 안내 웹 페이지를 앱 안에서 불러온다(인터넷이 있어야 한다)
   │
   └─ [검색] 칸 넷(전시사 · 세션 · 연사 · 위치), 비었을 때 "결과 없음"

   ┄ [지도 화면] 열리지 않았다(메뉴 · 타일 어디에도 지도 줄 없음). 앱 안내문은 파란 점 길 안내가 있다고 말한다(7.3)
```

- **길(탭 · 메뉴):** **아래 탭은 본 화면 어디에도 없다.** 위 막대의 왼쪽에 메뉴(홈 · 내 CES · 연결 · 행사 정보 같은 허브 화면) 또는 뒤로가 오고 오른쪽에 검색이 온다. 사이드 메뉴 · 타일 모음 화면(내 CES · 연결 · 행사 정보)이 뼈대이고, 큰 타일 한 칸이 한 기능이다. 앱을 열면 홈이다.
- 우리 앱은 아래 탭 넷(지도 · 동선 · 일기 · 설정)이고 앱을 열면 지도다. 공식 앱은 지도가 아니라 **목록(전시사 · 일정)이 중심**이다.

## 4. 기능표

공식 앱에 있음 → 우리 앱의 있음 · 일부 · 없음. "기준표" 번호는 [공식앱_기준표.md](../공식앱_기준표.md)의 줄이다. 판정은 2026-11-22 main 기준이다.

| 기능 | 공식 앱(근거) | 우리 앱 | 기준표 |
|---|---|---|---|
| 내 일정 만들기 · 고치기, 웹 일정과 맞춤 | 두 칸 "일정 / 내 일정"(그림) · 웹과 동기(글) | **일부** — 동선 안의 내 일정과 세션 담기. 로그인 동기는 없다 | 1 |
| 날짜 띠 + 거르기 칩 | **본 것**: 날짜 띠 여섯(1/4 ~ 1/9) + 칩 둘(거르기 · 주요). 거르기는 전체 화면 창(시간대 · 분류 넷) | **일부** — 세션 찾기에 날짜 · 낱말 찾기가 있다. 칩으로 거르는 길은 없다 | 새 21 |
| 세션 목록(때 · 곳 · 제목) | **본 것**(일정 화면 · 세션 화면) | **있음** — 세션 일정(동선 안) | 3 |
| 유료 세션 표시 | **본 것**: 녹색 원 $ (글 없음). 대상 제한 태그(매체 전용 같은)가 때 줄 오른쪽에 말줄임으로 붙음 | **없음** — 우리 세션 자료에 유료 여부가 있는지는 확인하지 않았다 | 새 22 |
| 세션 메모 · 설문 · 분류 | **본 것**: 세션 화면 맨 아래에 분류(주제 · 트랙 · 종류 · 장소) · 설문 한 줄 · 메모 칸 | **없음** — 세션별 메모는 없다(일기는 회사별) | 기준표 미반영 |

## 7. 실제 앱에서 본 것 (2026-11-22 아이폰 미러링)

**어떻게 봤나.** 주인의 아이폰에 떠 있는 공식 앱("CES 2027")을 미러링 창으로 직접 눌러 넘기며 읽었다. 폰 시계 19:45 ~ 19:52, 약 30화면이다. 눌러도 되는 것(화면 넘기기 · 목록 열기 · 거르기 창 열고 닫기)만 눌렀다. 로그인 · 가입 · 즐겨찾기 · 일정 담기 · 설정 바꾸기 · 보내기 · 공유는 하나도 누르지 않았다. 그림은 저장소 밖 `~/Downloads/ces2026-app/screens/live-*.png` 29장이다. 이 문서에는 우리 말 관찰과 수치만 적었다(공식 앱의 그림 · 문구 · 아이콘은 가져오지 않았다).

- 앞 일꾼이 같은 날 19:30 ~ 19:41에 읽기만 해서 본 **환영 화면 첫 장**(남색 막대 제목 · 큰 그림 · 큰 파란 단추 "로그인" + 글자 단추 "나중에" · 아래 점 넷 · 아래 탭 없음)도 이 절에 합쳤다. 나는 그 화면을 다시 보지 못했다(내가 이어받았을 때는 이미 앱 안이었다).
- 내가 연결했을 때 "로그인할 수 없다 · 이 계정의 CES 신원을 불러올 수 없다"는 오류 창이 떠 있었다(계정 번호가 적혀 있어 옮기지 않았다). "확인"만 눌러 닫았다. 그 뒤로 **로그인 안 한 상태**("내 프로필"에 "로그인 안 함")로 쭉 읽었다. 로그인 권한 · 알림 · 위치 · 블루투스 · 추적을 묻는 iOS 창은 한 번도 뜨지 않았다.
- 행사 한 달 반 전이라 목록 · 일정 자료가 견본이거나 덜 채워졌을 수 있다. 앱 안내문 한 곳에 지난해 이름("CES 2026")이 남아 있었다.

### 7.3 눈에 띄는 것들

- **지도가 없다.** 사이드 메뉴 · 홈 · 내 CES · 연결 · 행사 정보 · 검색 어디에도 지도 줄이 없다. 회사 · 세션 · 부스 화면의 핀 아이콘은 지도가 아니라 "그 자리의 전시사 목록" 화면으로 간다. 그래서 확대 단계 · 파란 점 · 층 고르기 · 지도 위 부스 카드 · 찾기는 **못 봤다**. 앱 안내문은 파란 점 길 안내를 베네시안 엑스포와 LVCC에서만 쓸 수 있다고 하고, 블루투스와 위치 허용을 요청하며, 만달레이 베이 · 아리아 · 폰테인블로는 안 된다고 적었다. 지도가 로그인 뒤에만 열리는지, 행사가 가까워져야 열리는지는 모른다.
- **공식 앱은 목록이 중심이다.** 일정 · 전시사 · 연사 · 즐겨찾기 모두 "하트 + 이름 + 보조 한 줄" 목록이고, 부스를 찾으면 카드가 열린다. 우리는 지도에서 누르고 동선으로 걷는다. 이것이 두 앱의 가장 큰 구조 차이다.
- **회사 카드에 세션이 든다.** 그 회사가 나오는 세션이 때 · 날짜 · 곳과 함께 카드에 줄로 붙는다. 큰 회사는 **위치 줄이 둘 이상**(전시장 두 곳)이다.
- **메모가 곳곳에 있다.** 회사 카드 · 세션 화면 맨 아래에 메모 칸이 있고 "메모 보내기" 줄이 붙는다. 내 메모 화면은 칸 셋 + "모두 내보내기"다. 일기가 같은 일을 한다.
- **설정은 항목 넷뿐이다.** ① 푸시 알림(폰 설정으로 보냄) ② 위치 알림(스위치, 꺼짐) ③ 분석 수집 허용(스위치, **켜짐 기본**) ④ 행사 모드: 현장(행사 시간대) / 집(내 폰 시간대). **글자 크기 · 언어 · 오프라인 줄은 없다.** 앱 안내문 설정 쪽에는 참가자 연결 공개 여부를 정하는 줄이 있다고 적혀 있으나(로그인 뒤에만) 로그인 전 화면에는 없다.
- **빈 화면은 모두 한 꼴이다.** 그림(달력 · 하트 · 없음) + 굵은 한 줄 + 설명 한 ~ 두 줄. 즐겨찾기 빈 화면은 "하트를 눌러 고르라"고 **다음 동작을 알려 준다**.
- **로그인은 건너뛸 수 있다**(환영 화면의 "나중에"). 건너뛰면 전시사 · 일정 · 연사 · 설정 · 행사 정보는 열린다. 일정에 담기 · 추천 · 참가자 명단 · 연락처 연결은 로그인이 필요하다.
- **일정 날짜 띠는 1/4부터다**(1/4 월 · 1/5 화 사전 행사와 매체 행사, 1/6 ~ 1/9 본 행사). 우리 날짜 칩은 1/6 ~ 1/9 + 미정이다.
- **행사 정보 타일은 웹 페이지다**(ces.tech 안내 글을 앱 안에서 불러온다). 불러오는 동안 빙글 돈다. 인터넷이 없을 때 어떻게 되는지는 시험하지 못했다(네트워크 끄기 금지).
- 앱 안내문이 가리키는 기능은 열네 가지(로그인 · 길 찾기 · 연락처 나누기 · 참가자 만나기 · 즐겨찾기 · 일정 담기 · 메모 · 행사 알림 · 세션 알림 · 설정 · 생중계 · 세션 평가 · 비상 신고 · 앱 소개)다. 이 중 **세션 평가**와 **비상 신고**는 우리 앱에 없다.

### 7.4 로그인 때문에 못 본 것

로그인 · 계정 만들기 · 약관 동의는 하지 않았다(지킬 선). 아래는 눌러 보니 로그인이 필요해서 멈춘 것이다.

- 연락처 나누기(연락처 연결 타일 → CES 계정 로그인 웹 창이 뜸), 참가자 명단, 참가자 추천, 전시사 추천(로그인 안내 + 단추 하나). 받은편지 · 프로필 관리 · 내 CES의 일정 타일은 안 눌렀다.
- 그래서 **명함 · QR 화면은 못 봤다.** 공식 앱의 "바뀌는 QR"이 어떤 모습인지는 모른다.

### 7.5 아직 못 본 것과 까닭

| 못 본 것 | 까닭 |
|---|---|
| 지도 화면(홀 · 부스 · 층 · 파란 점 · 확대 단계 · 부스 카드 · 찾기) | 열리지 않았다. 로그인 뒤 · 행사 가까이에 열리는지 모른다 |
| 연락처 나누기 · 명함 · QR · 참가자 · 받은편지 | 로그인 필요 |
| 글자 크기 | 설정 어디에도 없다(없다고 본다). 폰 시스템 글자 크기를 따르는지는 시험하지 못했다 |
| 오프라인 | 네트워크를 바꾸는 일이 막혀 있다 |
| 검색 결과 | 글자를 넣는 일이 막혀 있다 |
| 환영 화면 둘째 ~ 넷째 장 | 내가 앱 안에서 이어받았다. 앞 일꾼은 첫 장만 봤다 |
| 일정 줄의 "추천 · 까닭 한 줄" | 로그인 전이라 추천이 없었다 |

### 7.6 공식 웹 플래너에서 본 것 (2026-11-22, 로그인해서)

폰 앱은 로그인 없이 읽었고, 같은 날 이재엽이 만든 CES 계정으로 전시사 웹의 **My Show Planner**에 로그인해 따로 보았다(Aside, 전시사 하나를 담았다 바로 뺌). 자세한 표와 우리 앱에 더할 것(안)은 [ces2027-계정과-웹플래너.md](ces2027-계정과-웹플래너.md)에 있고, 기준표에는 28 ~ 34번 줄로 들어갔다([공식앱_기준표.md](../공식앱_기준표.md) 2.4절).

- **웹 플래너에 있는 것:** 전시사 담기 · 담은 목록(이름순 · 부스 번호순 · 다녀온 곳 순) · 전시사마다 **메모 · 사진 · 다녀옴 표시** · 내 일정 · 제품 · 자료 · 특가 담기 · 추천 · 일정 인쇄 · 배지 잇기. 영어만이고 한 사람 것만 모이며 로그인해야 쓴다.
- **폰 앱과 견주면:** 메모는 둘 다 있다(앱에는 회사 · 세션 메모 칸과 "모두 내보내기", 웹에는 전시사 메모). **사진과 다녀옴은 웹 플래너에서만 보았다.** 폰 앱의 로그인 없는 화면(7.1)에서는 사진 칸도 다녀옴 표시도 보지 못했다. 로그인 뒤에 있는지는 모른다.
- **웹 플래너에 담은 전시사가 폰 앱 즐겨찾기에도 보이는지**는 폰 앱이 로그인이 필요해 보지 못했다(7.4). 로그인 없는 앱에는 즐겨찾기가 비어 있었다.
- 앞에서 "공식 앱에서 일기 · 메모를 찾지 못했다"고 적었던 말은 맞지 않다. 폰 앱에는 메모가 있고(7.3), 웹 플래너에는 메모 · 사진 · 다녀옴이 있다. 없는 것은 "본 것 · 느낀 점 · 네 태그"로 정리해 주는 일기와, 여러 사람의 것을 모아 한 장으로 정리하는 일이다.

## 8. 우리 앱에 없는 큰 것 다섯

1. **부스 단위 실내 지도 + 층 + 파란 점 1 ~ 3m 길 안내** — 정식 배치도와 현장 장비가 있어야 한다. 배치도가 열리면 부스 자리는 반영되지만 층과 파란 점은 따로다.
2. **사람 잇기** — 서로 수락하는 연락처 교환 · 바뀌는 QR · 앱 안 연결. 서버가 있어야 한다.
3. **계정으로 일정 맞추기와 닫힌 앱의 알림** — 웹 일정과 맞추기 · 줄별 알람 푸시. 서버와 로그인이 있어야 한다.
4. **실시간 번역과 실시간 교통 대기** — 공식 앱의 서버 자료다(번역은 이재엽이 지웠다).
5. **AI 챗봇(목소리 · 여러 언어)과 사진 · 연사가 풍부한 전시사 정보** — 글을 지어내는 서버와 공식 자료 접근이 필요하다.

## 9. 주인이 정할 것 · 정한 것 (2026-11-22)

### 정한 것 (이재엽이 버튼으로 정했다, 11/22)

- **1/5(화) 사전 일정을 날짜 띠에 넣는다.** (1/4 월은 매체 전용이라 넣지 않는다.)
- **회사 카드에 "이 회사 세션" 줄과 둘째 부스 위치 줄을 넣는다.**
- **설정에 "이 폰의 내 자료 지우기"(두 번 확인)를 넣는다.**
- **직접 로그인해서 다시 읽기는 하지 않는다.** 지금 본 것으로 충분하다. 그래서 지도 · 연락처 · 명함이 로그인 뒤에 열리는지는 모르는 채로 둔다.
- 위 셋을 짓는 일꾼이 따로 돈다(방 `ces-다시짓기-1-번역지우기`). 요구사항.md · 작업.md를 같이 고칠 수 있다.

기본값으로 둔 것(따로 묻지 않았다):

- 서버 없는 원칙을 그대로 둔다(8절 2 · 3번은 서버 없이 못 한다).
- 지도가 첫 화면이다. 다만 지도가 쓰이지 않을 때를 위해 동선 · 회사 찾기가 막히지 않게 한다.
- 글자 크기에 "폰 설정 따름" 단계는 두지 않는다.
- 화면 처음 한 화면의 설명 글은 60자 안으로 한다.
- 연사 자료는 읽지 않는다(기준표 2.1절 · 16번).
