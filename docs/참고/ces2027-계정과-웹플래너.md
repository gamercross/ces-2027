# CES 공식 계정과 웹 플래너

이재엽의 말(2026-11-22, Aside 채팅, 원문 그대로):

> "지금 iphone 미러링을 해둔상태야 지금 ces2027을 다운 받은 상태야 거기에 회원가입을 하고 앱에 기능들을 정리해서 내앱에 기능들을 통합해서 업데이트 하고 싶어 왜 할려고 하면 한국어가 없고 내가 이제 우리만의 여행을 가는거니까 저장하고 일기들을 받아서 한번에 정리하고 싶어서야"

- 이 문서는 [ces2026-앱-살펴보기.md](ces2026-앱-살펴보기.md) 7절 "주인이 실제 앱에서 본 것"의 첫 묶음이다. 웹 플래너는 로그인해서 봤다. 폰 앱 안 화면은 같은 날 물개의 일꾼이 로그인 없이 읽은 결과가 살펴보기 7절에 있고, 4절에 그 결과를 채웠다. 이 문서의 내용은 기준표 [2.4절](../공식앱_기준표.md)에 줄(28 ~ 34번)로, 요구는 [요구사항.md](../../요구사항.md)에 R46 ~ R49 (안)으로 합쳤다.
- 개인 자료는 적지 않았다. 이메일 · 비밀번호 · 배지 · 사는 곳 · 화면 그림은 레포에 넣지 않는다.
- 공식 쪽의 이름 · 로고 · 화면 모양은 베끼지 않는다. 기능만 우리 말로 적었다.

## 1. 한 것과 못 한 것 (2026-11-22)

| 일 | 결과 |
|---|---|
| CES 계정 만들기 | `account.cta.tech`에서 만들었다. 묻는 것은 이름 · 성 · 이메일 · 회사 · 직함 · 비밀번호(12자 이상, 아이디의 일부를 넣지 않는다) 여섯뿐이다. 나라 · 전화 · 여권은 묻지 않는다. 만든 뒤에 2단계 인증은 고를 수 있다 |
| 로그인 | 로그인 화면(`login.cta.tech`)은 브라우저 말을 따라 한국어로 뜬다(이메일 → 다음 → 비밀번호 → 필요하면 이메일 확인). 이재엽이 비밀번호를 새로 정해 로그인했다. 계정 첫 화면에는 앱 여섯이 있다: CES Registration · CES.tech · CTA.tech · CTA Store · CTA Member Account · Exhibitor Dashboard & Registration |
| My Show Planner (전시사 웹의 플래너) | CES 계정으로 들어간 뒤 한 번 더 만든다(무료). 묻는 것: 이름 · 성 · 도시 · 주 · 나라, "전시사와 연결" 예 / 아니요(예를 고르면 담은 전시사에 이메일이 가고 광고 메일이 올 수 있다), 로봇 확인. **아니요**로 만들었다 |
| CES 등록(배지) | 하지 않았다. 등록은 연수 쪽에서 한다는 안내가 있어 따로 하면 겹친다 |
| 폰 앱 안 화면 | Aside는 못 봤다(아이폰 미러링 창은 Aside가 보거나 누를 수 없다). 같은 날 물개의 일꾼이 mirroir로 읽었다 → 4절 |

## 2. 웹 플래너에서 본 것 (로그인해서, 2026-11-22)

전시사 하나를 담아 보고 바로 뺐다. 지금 플래너는 비어 있다.

| 칸 | 하는 일 | 우리 앱 |
|---|---|---|
| 전시사 담기 | 전시사 쪽의 "Add to Planner" 한 번 → "Saved" | 관심(R4) |
| 담은 전시사 목록 | 격자 · 줄 보기, 이름순 · 부스 번호순 · 다녀온 곳 순 | 관심 → 동선(R5). 부스 번호순은 걷는 차례가 대신한다 |
| 전시사마다 메모 (Add Note) | 담은 전시사 줄 아래 메모 | 회사 일기(R14) |
| 전시사마다 사진 (Add a New Photo · My Photos) | 담은 전시사에 사진을 붙이고 사진 칸에서 모아 본다 | **없음** |
| 다녀옴 (Mark As Visited) | 다녀온 곳 표시, 다녀온 곳 순으로 줄 세우기 | 동선 줄의 "봤다" · 30m 안의 "도착했다 · 봤다"(R45). 본 곳만 거르는 길은 없다 |
| 내 일정 (My Events) | 내 일정 넣기 · 세션 찾아 담기 | 내 일정(R19) · 세션 일정(R33) |
| 제품 · 전시사 자료 · 특가 (Products · Collateral · Special Offers) | 제품 · 소개 자료 · 특가를 담는다 | 없음(공식 쪽에 둔다) |
| 연락 (Contact Us) | 연락한 전시사 | 만난 사람(R34)은 사람이고, 이것은 전시사다 |
| 추천 (Recommendations) | 전시사 · 세션 두 칸. 관심을 정하기 전이라 이름이 숫자 · A로 시작하는 18곳이 나왔다 | 추천(R20): 공식 자료 근거 + 까닭 한 줄 |
| 인쇄 (Print Agenda) | 일정을 인쇄한다 | 동선 글 · 마크다운 · CSV 내보내기 |
| 배지 잇기 (Associate Badge) | 배지가 나오면 플래너에 잇는다 | 해당 없음(배지가 나오면 각자 공식 쪽에서) |
| 말 | 플래너 · 전시사 쪽은 영어만 | 한국어 |

앞 문서가 처음에는 "공식 앱에서 일기 · 메모 기능을 찾지 못했다"고 적었으나, 폰 앱을 직접 읽은 뒤 고쳤다(살펴보기 4절 · 7.3 · [단계별-디자인-준비.md](단계별-디자인-준비.md) 6단계). **공식 웹 플래너에는 전시사마다 메모 · 사진 · 다녀옴이 있다.** 폰 앱에는 회사 · 세션 메모 칸이 있고 사진 칸은 보지 못했다(4절 확인 4). 다른 점은 셋이다: 영어만, 한 사람 것만(남과 모으지 않는다), 로그인해야 쓴다.

## 3. 공식 쪽에 그대로 두는 것

배지 · 서로 수락하는 연락처 교환(Attendee Connect) · 세션 실시간 번역 · 교통 실시간 대기 · Ask AI · 긴급 신고 · 생중계는 공식 앱이 한다. 우리 앱은 따라 하지 않는다([공식앱_기준표.md](../공식앱_기준표.md) 11 · 12 · 13 · 14 · 15 · 20번 그대로).

- Ask AI는 공식 안내가 "여러 언어"를 지원한다고 한다. 한국어로 물어도 되는지는 폰에서 본다(확인 2).

## 4. 폰 앱에서 볼 것 · 본 것 (2026-11-22)

물개의 일꾼이 같은 날 저녁 아이폰 미러링(mirroir)으로 공식 앱을 직접 넘겨 읽었다(로그인 없이, 약 30화면, 보기만. 자세한 것은 [ces2026-앱-살펴보기.md](ces2026-앱-살펴보기.md) 7절). 그림은 저장소 밖에 있고 레포에 넣지 않았다.

| 확인 | 물음 | 결과 | 왜 |
|---|---|---|---|
| 1 | 웹 플래너에 담은 전시사가 폰 앱 즐겨찾기에도 보이나 | **못 봤다.** 로그인이 필요하다. 로그인 없는 앱에서 즐겨찾기는 비어 있었다 | 5절 "공식 앱에도 담기"가 쓸모 있는지 정한다 → 로그인 뒤에 다시 본다 |
| 2 | Ask AI에 한국어로 물으면 한국어로 답하나 | **못 봤다.** 로그인 없는 화면에서는 Ask AI 줄을 만나지 못했다(앱 안내문에는 있다) | 한국어 사용자에게 알려 줄지 정한다 |
| 3 | 비행기 모드에서 지도 · 즐겨찾기가 열리나 | **시험하지 못했다.** 네트워크를 끄는 일이 막혀 있었다. 행사 정보 타일은 웹 페이지를 불러온다. 설정에는 오프라인 줄이 없다 | 기준표 "오프라인 못 봄" 줄은 그대로 둔다 |
| 4 | 앱 안에 회사 메모 · 사진이 있나 | **메모는 있다.** 회사 카드와 세션 화면 맨 아래에 메모 칸과 "메모 보내기" 줄이 있고, 내 메모 화면에는 칸 셋(전시사 · 세션 · 참가자)과 "모두 내보내기"가 있다. **사진은 못 봤다**(메모 칸 말고 사진 칸 · 사진 단추가 화면에 없었다) | 2절과 견준다: 웹 플래너의 메모는 폰 앱에도 있고, 사진과 다녀옴은 웹 플래너에서만 보았다 |

- 못 본 것 둘(확인 1 · 2)은 로그인이 필요해서다. 로그인은 하지 않았다(지킬 선).
- 이재엽이 로그인해서 다시 읽게 하는 일은 하지 않기로 정했다([살펴보기 9절](ces2026-앱-살펴보기.md)). 확인 1 · 2는 못 본 채로 둔다.

## 5. 우리 앱에 더할 것 (안)

이재엽의 까닭 넷에 맞췄다. 크기는 어림이다.

| 까닭 | 더할 것 | 공식 쪽 | 크기 | 권함 |
|---|---|---|---|---|
| 일기들을 받아서 한번에 정리 | **모은 일기 열기:** 설정의 내보내기 묶음에 "모은 일기 열기"를 둔다. 받은 `ces2027-일기-*.json` 여러 개를 한 번에 고르면 네 태그 × 회사로 묶은 한 장이 화면에 나오고, `한장.md`로 내려받는다. 같은 일기는 한 번만 센다. 정리는 지금 `ces-data`의 `diary.rs`(합치기 · 태그 칸 나누기)를 WASM으로 돌린다. 그 화면을 열 때만 불러와 첫 화면 2초를 지킨다. 모은 파일과 한 장은 폰에 남기지 않는다(보고 내려받기만) | 없다. 공식은 한 사람 것만 있다 | 중간 | 1순위 |
| 저장 | **본 곳만 · 안 본 곳만:** 동선 위 날짜 칩 줄 끝에 "안 본 곳" 칩 하나. "봤다"를 누른 곳을 걸러 오늘 남은 곳만 보인다 | 다녀옴 · 다녀온 곳 순 | 작다 | 2순위 |
| 저장 | **일기 사진 한 장:** 회사 일기에 사진 한 장(폰에서 줄여 이 폰에만). 보내기 파일에는 기본으로 넣지 않고, 켜면 넣는다 | 사진 (Add a New Photo · My Photos) | 중간 | 이재엽이 정한다 |
| 우리만의 여행 | **공식 앱에도 담기:** 설정의 내보내기에 "관심 회사 공식 링크" 한 장(회사마다 공식 전시사 쪽 링크 한 줄). 현장에서 공식 앱의 실내 길 안내를 쓰고 싶은 사람이 공식 플래너에 손으로 담는다. 우리 앱은 로그인하지 않는다 | 전시사 담기 | 작다 | 3순위, 확인 1 뒤 |
| 우리만의 여행 | 이미 있다: 우리 일정은 "시간과 일정" 파일로 단톡방에서 건넨다([내일정_파일.md](../내일정_파일.md)). 레포에는 넣지 않는다 | | | 그대로 |
| 한국어 | 이미 있다: 화면 · 일기 · 정리 한 장이 한국어다. 회사 소개는 공식 영어 그대로다(번역은 11/22에 지웠다) | 영어만 | | 그대로 |

## 6. 요구사항에 넣을 줄 (안)

| R | 하고 싶은 것 | 말 | 끝난 모습 (확인할 수 있게) | 이정표 |
|---|---|---|---|---|
| R46 | 모은 일기 한 번에 정리 (앱 안) | 말15 · 말4 | 일기 파일 셋을 한 번에 고르면 네 태그 × 회사 한 장이 화면에 나오고 `한장.md`가 내려온다. `cargo run -p ces-data -- sort-diary`가 만든 한 장과 같은 내용이다. 비행기 모드에서도 된다. 고른 파일과 한 장이 폰 저장소에 남지 않는다 | M2 (안) |
| R47 | 본 곳 · 안 본 곳 거르기 | 말15 | 동선에서 "안 본 곳"을 고르면 "봤다"를 누른 회사가 빠지고, 날짜 칩의 곳 수도 같이 준다 | M2 (안) |
| R48 | 공식 링크 목록 내보내기 | 말15 | 설정 → 내보내기에서 관심 회사의 공식 전시사 쪽 링크를 줄마다 글로 내려받거나 복사한다 | M3 (안) |
| R49 | 일기 사진 (정할 것) | 말15 | 정하면 적는다 | - |

`말15`는 위 인용이다(2026-11-22, Aside 채팅).

## 7. 정할 것

- 일기 사진을 넣을지, 넣으면 보내기 파일에 같이 갈지
- R46을 M2(12/16)에 넣을지, M3(12/31)로 미룰지
- ~~폰 앱 화면을 누가 볼지~~ 정해졌다: 물개의 일꾼이 mirroir로 읽었다(4절). 로그인한 화면을 이재엽이 직접 읽게 할지는 **하지 않기로 정했다**(11/22, 지금 본 것으로 충분). 그래서 확인 1 · 2는 못 본 채로 둔다
