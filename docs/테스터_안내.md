# 테스터 안내: 폰으로 써 보고 결과 보내기

글로벌 어학연수 · CES 2027 준비 지도(비공식)를 폰으로 써 보는 안내다. 15분쯤 걸린다. 끝나면 맨 아래의 글을 복사해 단톡방에 붙인다.

- 열 주소: [https://gamercross.github.io/ces-2027/](https://gamercross.github.io/ces-2027/)
- **이름과 연락처는 적지 않는다.** 별명도 아무것이나 된다.
- 적은 것은 내 폰에만 남는다. 시험이 끝나면 브라우저의 사이트 자료를 지우면 다 없어진다.
- 앱에 보이는 연수 일정과 시간은 초안이다. 일정은 바뀔 수 있고, 운영팀 안내가 먼저다.

## 먼저: 어느 브라우저로 여나

| 폰 | 여는 곳 | 조심할 것 |
|---|---|---|
| 안드로이드 | 크롬 | 카카오톡 안에서 열리면 메뉴에서 "다른 브라우저로 열기"를 눌러 크롬으로 옮긴다 |
| 아이폰 | 사파리 | 카카오톡 안에서 열리면 오른쪽 아래 단추에서 "Safari로 열기"를 누른다 |

## 확인할 것 열 가지

### 1. 첫 화면이 뜨는 시간

주소를 처음 열고 "명함부터 만든다" 화면이 보일 때까지를 센다. 1초쯤인지, 2 ~ 3초인지, 더 오래인지만 적는다. 와이파이인지 LTE · 5G인지도 적는다.

### 2. 명함 QR 두 개

1. 별명을 적고 "나"에서 하나를 고른다.
2. 깃허브와 디스코드 칸에는 아무 주소나 넣어도 된다. 예: `https://github.com/octocat` 과 `https://discord.gg/abc`
3. "명함 만들기"를 누른다.

QR이 두 개 보이는지, 다른 폰의 카메라로 비추면 그 주소가 열리는지 본다.

### 3. 홈 화면에 추가

| 폰 | 하는 법 |
|---|---|
| 안드로이드 크롬 | 오른쪽 위 메뉴(점 셋) → "홈 화면에 추가" 또는 "앱 설치". 첫 화면 맨 아래 "인터넷 없이 쓰기" 칸에 단추가 보이면 그것을 눌러도 된다 |
| 아이폰 사파리 | 아래 가운데 공유 단추 → "홈 화면에 추가" |

홈 화면에 아이콘이 생기고, 눌렀을 때 주소 줄 없이 앱처럼 열리는지 본다.

### 4. 비행기 모드

1. 첫 화면 맨 아래 "인터넷 없이 쓰기"에 "인터넷 없이 열 준비가 됐다."가 보일 때까지 기다린다.
2. 아래 탭에서 회사 · 지도를 한 번씩 연다.
3. 비행기 모드를 켜고(와이파이도 끈다) 홈 화면의 아이콘으로 다시 연다.

명함 · 회사(찾기 칸에 "삼성") · 동선 · 지도 · 일기가 하나씩 열리는지 본다. 끝나면 비행기 모드를 끈다.

### 5. 위치와 홀 안 길

1. 지도에서 "GPS로 찾기"를 누르고 허락한다. 허락을 막았을 때 안내가 보이는지 확인한다.
2. "따라가기 켜기"를 누른 뒤 다른 화면으로 갔다 돌아온다. 따라가기가 멈췄다가 다시 자리를 받는지 본다.
3. 위치를 받을 수 있는 시험 브라우저라면 정확도가 낮거나 자리가 갑자기 바뀔 때 지도 점이 튀지 않고 안내가 나오는지 본다.
4. 부스 점 하나를 누르고 "홀 입구에서 길 보기" 또는 "내 자리에서 길 보기"를 누른다. 선과 "짐작" 안내가 보이는지 확인한다. 통로의 실제 자리는 현장에서 다시 봐야 한다.

### 6. 알림

| 폰 | 하는 법 |
|---|---|
| 안드로이드 크롬 | 첫 화면 아래 "알림" 칸 → "알림 켜기" → 허락 |
| 아이폰 사파리 | 3번에서 만든 홈 화면 아이콘으로 연 다음에만 "알림 켜기"가 된다. 사파리 탭에서는 안 되는 것이 맞다 |

"알림이 켜져 있다."로 바뀌는지 본다. 이어서 알림이 실제로 오는지 본다.

1. 지도 탭에서 점(부스) 하나를 누르고 "이벤트 있음으로 표시"를 누른다. 그 부스 번호를 기억한다.
2. 같은 화면의 "내 위치와 다음 갈 곳"에서 "가까운 부스 번호" 칸에 그 번호를 적고 "맞추기"를 누른다.

알림이 오는지, 알림 대신 탭 위에 "가까이에 명함 넣는 이벤트 부스" 띠만 보이는지, 아무것도 없는지 적는다.

알림을 거부했을 때도 화면의 띠와 안내가 남는지 본다. 같은 자리에 계속 있어도 같은 알림이 되풀이되지 않는지 확인한다. 앱을 뒤로 보냈다가 돌아오거나 인터넷을 끊은 뒤에도 현재 상태가 보이는지 적는다.

### 7. 폰 안에서 받아쓰기 모델 받기

"물어볼 말" 또는 "듣기"에서 "폰 안에서만"을 고른다. 이 폰이 받아쓰기를 지원하지 않으면 "모델 받기"를 누른다.

1. 받기 전에 약 45 MB와 "와이파이에서 받기를 권한다"가 보이는지 확인한다.
2. "그만둔다"를 눌렀을 때 받지 않는지, 다시 열면 모델을 받을 수 있는지 본다.
3. 와이파이에서 확인하고 받는다. 진행 크기가 보이고, 끝나면 "이제 인터넷 없이도 받아 적는다"가 나오는지 확인한다.
4. 인터넷을 끊고 화면을 다시 연다. 모델이 남아 있는지 본다. 모델을 지우면 저장 공간을 돌려받는다.

모델은 영어 받아쓰기만 한다. 시험용 데스크톱 Chromium 157에서는 약 36 MB를 받는 데 2분 38초가 걸렸다(느린 4G 흉내). 실제 폰과 통신망에서는 더 다를 수 있다. 모델이 되는지 확인한 브라우저도 데스크톱 Chromium뿐이다. 안드로이드 크롬 · 아이폰 사파리에서는 아직 확인하지 않았다. 폰 안 영한 번역은 아직 안 되는 기기가 많다. 안 됨과 까닭을 그대로 적는다.

### 8. 읽어 주기 · 받아 적기 · 글 옮기기 (폰 안에서만)

첫 화면의 "부스에서" 칸 → "물어볼 말"을 연다.

1. 질문 하나에서 "크게 띄우기"를 누른다. 화면 가득 영어가 보이면 된다.
2. "읽어 주기"를 누른다. 영어 소리가 나는지 듣는다(소리를 켠다).
3. 맨 아래 "이 폰에서 되는 것"의 세 줄(읽어 주기 · 글 옮기기 · 받아 적기)이 "됨"인지 "이 폰에서는 안 됨"인지 그대로 적는다.

"안 됨"이 나와도 잘못이 아니다. 폰이 못 하는 것을 그대로 보이는 것이 맞다.

### 9. 받아 적기 · 번역 (폰의 음성 인식 서비스)

같은 화면 맨 아래 "받아쓰기 · 번역을 어디서 하나"에서 "폰의 음성 인식 서비스"를 누른다. "인터넷이 필요하고 소리가 구글 · 애플로 간다."는 안내가 나오면 "알겠다 · 이 길로 한다"를 누른다. 내키지 않으면 "그만둔다"를 누르고 이 번호는 "안 함"으로 적는다.

1. "이 폰에서 되는 것"의 받아 적기가 "됨"으로 바뀌는지 본다.
2. "상대의 답"에서 "받아 적기"를 누르고 영어로 한 문장 말한다. 예: "This robot runs for eight hours." 글이 칸에 들어오는지 본다.
3. "직접 적어 묻기"에 한국어를 한 줄 적으면 "번역 사이트에서 열기" 링크가 보이는지 본다.

### 10. 듣기 → 일기 초안

첫 화면의 "부스에서" 칸 → "듣고 일기 초안"을 연다.

1. 회사 이름에 아무 이름이나 적는다.
2. "상대에게 알렸다 · 듣기 시작"을 누른다. 처음에는 "상대에게 알렸나요?"를 묻는다. "알렸다 · 듣기 시작"을 누른다.
3. 영어로 두세 문장 말한다. 받아 적기가 안 되는 폰이면 "손으로 적기"에 한 줄 적고 "줄 넣기"를 누른다.
4. "멈추고 일기 초안 만들기"(또는 "적은 것으로 초안 만들기")를 누른다.

"일기 초안 다듬기" 화면이 열리고 들은 글이 들어 있는지 본다. 느낀 점을 한 줄 적고 "폰에 남기기"를 누른 뒤, 일기 목록에서 "녹음 듣기"가 되는지도 본다.

## 결과 보내기

아래 글을 복사해 단톡방에 붙이고, 맞는 것만 남기고 지운다. 이름과 연락처는 적지 않는다.

```
[CES 앱 시험]
폰: 안드로이드 크롬 / 아이폰 사파리
폰 기종과 OS 판:
1 첫 화면: 1초쯤 / 2~3초 / 더 오래 (와이파이 / LTE)
2 명함 QR 두 개: 보임 / 안 보임 · 다른 폰으로 읽힘 / 안 읽힘
3 홈 화면에 추가: 됨 / 안 됨
4 비행기 모드: 명함 O X · 회사 찾기 O X · 동선 O X · 지도 O X · 일기 O X
5 위치 · 홀 안 길: 허락 O X · 따라오기 O X · 짐작 길 O X · 낮은 정확도에서 점프 O X
6 알림: 켜짐 / 거부 / 지원 안 함 · 반복 없음 O X · 인터넷 없음 O X
7 폰 안 모델: 받기 전 크기와 와이파이 안내 O X · 받은 크기 · 걸린 시간 · 오프라인 받아쓰기 O X
8 폰 안에서만: 읽어 주기 O X · 받아 적기 O X · 글 옮기기 O X
9 음성 인식 서비스: 받아 적기 O X · 번역 링크 O X / 안 함
10 듣기 → 일기 초안: 됨 / 안 됨 · 녹음 듣기 O X
11 남의 명함 받기: 카메라로 읽기 O X / 손으로 넣기 O X · 만난 사람에 저장 O X · 고치기와 지우기 O X
12 공식 셔틀: /transit이 열림 O X · 노선과 시간 O X · 확인 필요를 알아볼 수 있음 O X
13 회사 로고: 끔 / 켬 · "로고 보기"를 누르면 공식 새 창이 열림 O X · 새 창에 그림이 보임 O X
막힌 곳 한 줄:
```
