# CES 공식 앱 기준표

확인 날짜: 2026-11-21. 출처:
- https://www.ces.tech/app
- https://apps.apple.com/us/app/ces-2027/id6443741077
- https://play.google.com/store/apps/details?id=com.cta.cestech
- https://www.ces.tech/attendee-guides/transportation

이 문서는 공식 앱의 기능을 우리 판과 비교한 것이다. 이 앱은 비공식이다. 공식 이름 · 로고 · 화면 모양을 베끼지 않는다.

| 공식 앱 기능 | 우리 앱 | 판정 | 우리 판으로 만든 것 | 못 하는 까닭 |
|---|---|---|---|---|
| 일정 만들기 · 고치기 | 세션 일정과 내 일정이 있다 | **됨** | 세션을 찾고 날짜별로 보며 내 일정에 넣거나 빼는 코드와 폰 저장을 만든다 | 2027 공식 세션 목록이 전체로 확인되지 않아 목록은 확인된 기조연설부터 부분 제공한다 |
| 꼭 볼 전시사 즐겨찾기 | 관심 회사와 추천 즐겨찾기 | **됨** | 회사 화면에서 관심을 누르면 동선과 지도에 남는다 | 전시사 자료가 공식 검색에서 받은 날에 따라 늦거나 비어 있을 수 있다 |
| 기조연설 · 세션 목록, 생중계 · 다시 보기 | 세션 일정 화면과 공식 출처 링크 | **일부** | 찾기 · 날짜별 보기 · 내 일정 넣기와 생중계/다시 보기 링크 칸을 만든다 | 공식 2027 세션 목록과 영상 주소가 아직 이 자료에 없다 |
| 3D 지도와 확대, 부스 누르기, 회사 정보 · 사진 · 링크 · 실내 길 안내 | 2D/3D 지도와 부스 카드 | **일부** | 확대 · 캠퍼스 · 부스 누르기 · 회사 공식 링크 · Maps 길찾기를 넣는다 | 홀 안 진짜 통로와 정식 배치도가 없고 공식 사진/로고 주소가 온 자료에 없을 수 있다 |
| 교통 안내와 셔틀 | 이동 탭과 셔틀 자료 | **일부** | Tech Express Route 9, C Space Route 7, 호텔 셔틀과 타는 곳을 공식 출처로 넣는다 | 셔틀 시간표와 호텔별 시간은 공식 PDF/2027 안내를 더 확인하기 전까지 확인 필요로 둔다 |
| 일부 세션 번역 | 물어볼 말과 듣기 번역은 있다 | **일부** | 세션 전용 라이브 번역이 아니라 폰 안 또는 선택한 음성 서비스를 쓰는 한국어/영어 읽기·번역을 만든다 | 세션 오디오를 공식 세션과 연결한 실시간 다국어 자막은 서버와 라이선스 없이 못 한다 |
| QR로 서로 연락처 나누기 | 명함 교환 QR과 카메라 읽기 | **일부** | 명함 교환 QR을 만들고 카메라 또는 손 입력으로 만난 사람을 폰에 저장한다. 일기와 연결한다 | 공식 Attendee Connect의 수락·거절 서버와 동적 MagicBadge는 로그인 없는 공개 판에서 만들지 않는다 |
| AI 챗봇 | 물어보기 화면과 미리 번역한 자료 검색 | **일부** | 서버 없이 회사 · 세션 · 알아둘 것 · 이동 · 따로 신청 자료를 한 곳에서 찾고 자주 묻는 답을 미리 둔다 | 답을 지어내는 생성형 AI와 서버는 없으며, 자료 밖은 답하지 않는다 |
| CES 계정 로그인 | 로그인하지 않는다 | **없음** | 계정 없이 모든 기능을 폰 저장과 공개 자료로 만든다 | 공개 레포 · 키 없는 앱 · 폰 안 저장 규칙으로 CES 계정 서버를 붙이지 않는다 |
