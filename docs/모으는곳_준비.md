# 모으는 곳 준비

정하는 것은 이재엽이다. 여기에는 두 길을 고르기만 하면 되게 적었다. 어느 쪽이든 폰 밖으로 나가는 것은 보내기를 누른 일기와 별명 · 태그뿐이다.

## 길 1. 파일로 받기 (지금 그대로 된다)

1. 각자 일기 화면에서 "보내기"를 누른다. `ces2027-일기-별명-날짜.json`이 내려온다.
2. 그 파일을 정리하는 사람에게 건넨다 (단톡방 · 메일).
3. 정리하는 사람이 파일들을 한 폴더에 모으고 돌린다:

   ```sh
   cargo run -p ces-data -- sort-diary --in 모은일기 --out 한장.md
   ```

4. `한장.md`가 네 태그로 나누고 회사로 묶은 초안이다. 예시는 `docs/네태그_한장_예시.md`.

좋은 점: 만들 것이 없다. 인터넷이 약해도 된다. 걸리는 점: 파일을 건네는 손이 한 번 든다.

## 길 2. 구글 시트 한 장 (받는 코드는 준비, 보내 보지는 못했다)

**내가 확인하지 못한 것:** 실제 시트를 만들어 보내 보지 않았다 (계정으로 무엇을 만드는 일은 하지 않는다). 아래 코드는 구글 Apps Script의 흔한 꼴이지만, 처음 걸 때 일기 하나를 보내 시트에 줄이 생기는지 꼭 본다.

1. 구글 시트를 하나 만든다.
2. 시트의 확장 프로그램 → Apps Script에 아래를 붙여 넣는다.

   ```js
   // 준비 지도의 "보내기"가 보낸 일기 묶음을 시트 "일기"에 한 줄씩 적는다.
   function doPost(e) {
     var book = SpreadsheetApp.getActiveSpreadsheet();
     var sheet = book.getSheetByName('일기') || book.insertSheet('일기');
     if (sheet.getLastRow() === 0) {
       sheet.appendRow(['받은 때', '별명', '태그', '일기 id', '날짜', '회사', '부스', '본 것', '느낀 점', '누구에게']);
     }
     var data = JSON.parse(e.postData.contents);
     if (data.app !== 'ces-2027-diary' || data.v !== 1) {
       return ContentService.createTextOutput('다른 꼴이다');
     }
     var now = new Date();
     (data.entries || []).forEach(function (en) {
       sheet.appendRow([now, data.author.nick, data.author.tag, en.id, en.date, en.company, en.booth, en.saw, en.felt, (en.for || []).join(' ')]);
     });
     return ContentService.createTextOutput('받았다');
   }
   ```

3. 배포 → 새 배포 → 종류 "웹 앱", 실행은 "나", 접근은 "모든 사용자". 나온 주소(`https://script.google.com/macros/s/…/exec`)를 복사한다.
4. `config/settings.json`의 `collectorUrl`에 그 주소를 넣고 `collector`를 `"sheet"`로 적는다. PR로 올린다.
5. 폰에서 일기 하나를 보내 시트에 줄이 생기는지 본다.

걸리는 점:
- 그 주소를 아는 사람은 누구나 줄을 넣을 수 있다. 주소가 공개 레포의 설정 파일에 들어가므로, 연수가 끝나면 배포를 내린다.
- 폰은 답을 읽을 수 없는 방식으로 보낸다. "보냈다"는 표시는 도착을 보증하지 않는다. 도착은 시트에서 본다.
- 시트의 줄을 한 장으로 만드는 길은 아직 없다. 시트로 정하면 자료 도구에 "시트에서 받은 CSV 읽기"를 더한다 (작은 일이다).

## 고를 때 볼 것

| | 파일로 받기 | 구글 시트 |
|---|---|---|
| 지금 되나 | 된다 | 받는 코드를 붙이고 주소를 넣어야 한다 |
| 사람 손 | 파일을 건넨다 | 누르면 끝 |
| 인터넷 | 건넬 때만 | 보낼 때 있어야 한다 |
| 밖에 남는 것 | 건넨 파일 | 구글 시트 (이재엽 계정) |
| 한 장으로 | 도구가 바로 읽는다 | CSV 읽기를 더해야 한다 |
