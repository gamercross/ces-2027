# CES 2027 기록 틀

## 3. 다녀와서 정리 한 장 (1/15 ~)

| 칸 | 내용 |
|---|---|
| 기대했던 것 | 출발 전 판에서 |
| 실제로 본 것 | 하루 한 장들에서 |
| 달랐던 것과 까닭 | 내 말 (지식 후보) |
| 같이 간 사람에게 물어 고친 것 | 태그마다 한 사람씩 |
| 나눌 곳 | 인스타 · GitHub · MY-OS-APP |

네 태그로 나눈 이 한 장이 이슈 #18의 끝난 모습이다. 맞다고 확정한 줄만 지식으로 둔다.
