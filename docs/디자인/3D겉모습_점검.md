# 3D 겉모습 디자인 점검 (2026-11-26, R67)

## 정한 꼴

- 둘레 건물: 오픈스트리트맵 윤곽을 연한 회색(`--map-decor`)으로 세운다. 장소(홀 · 호텔)는 지금 색 그대로, 테두리는 강조색. 그래서 "CES 장소"와 "둘레 건물"이 색 하나로 갈린다.
- 높이: 아는 높이 → 층 수 × 3.5m → 어림(넓으면 12m · 작으면 7m). 어림인 건물이 많아 높이로 무엇을 알리지는 않는다(길 찾는 눈대중만).
- 길은 바닥 선, 모노레일은 9m 뜬 점선(`--map-transit`)과 정거장 점 · 이름. 출입구는 홀 벽의 작은 진한 표시(홀 단계부터).
- 홀 안: 지붕을 벗기고 바닥 위에 부스 칸을 3m 상자로(2D와 같은 자리 · 크기). 관심 · 갈 곳 회사 상자만 강조색. 가까운 벽은 22%로 옅게, 위층 회의실은 45%로 비쳐 아래가 보인다.
- 글자: 갈 곳 번호 원은 가까이 꽂히면 서로 비킨다(줄기가 기운다). 이름은 오른쪽 → 왼쪽 → 위 → 아래, 긴 이름 → 7자 → 5자 차례로 자리를 찾고 차례 선 위에는 놓지 않는다. 번호는 늘 보이고, 다음 갈 곳 이름은 남는다. 위 한 줄 "부스 자리는 대략 · 정식 배치도가 열리면 바뀐다"는 한 줄로만(넘치면 "…"), 아래 "© OpenStreetMap 기여자"는 3D에도.
- 폰이 덜 뜨겁게: 계속 도는 그리기 고리는 없다(손을 댈 때만 다시 그린다). 카메라 쪽 옆면만 그리고, 화면 밖은 건너뛰고, 작게 보이는 건물 · 돌리는 동안은 지붕만 그린다.

## 도구로 본 것

- 디자인 스킬 `ui-ux-pro-max` 찾기 셋("main thread budget frame" · "reduced motion battery" ux, "depth shading performance" threejs):
  - 먼 것은 단순하게(LOD) · 작은 것은 그리지 않기 → 작게 보이는 건물 · 돌리는 동안은 지붕만, 화면 밖은 건너뛴다.
  - 빛 하나로 면마다 밝기를 달리해 깊이를 보인다 → 벽은 방향마다 0.72 ~ 0.88배 밝기(전과 같다).
  - 움직임은 한두 곳만 · 움직임 줄이기를 존중 → 3D는 스스로 움직이지 않는다(돌리기 · 날아가기는 손으로만).
- PELOVA `pelova_design_check`: 팔레트(강조 #5A6F96 하나) 기준 어긋남 0. 이 점검은 화면 파일을 0개 살폈다고 적었다(앱 폴더 `web/`에 닿지 않는다). 그래서 손으로 봤다: 이번에 더한 코드에 새 색 값은 없다(`--map-decor` · `--map-road` · `--map-transit` · `--map-plain` · `--accent` · `--ink` · `--ink-2`만).
