# 단톡방 안내 글 초안

보내지 않은 초안이다. **2026-11-21에 이재엽이 "팀 시험 뒤에 보낸다"로 정했다:** 12월 첫 주 시험에서 막힌 곳을 고친 다음, 이 초안을 같이 고치고 이재엽이 보낸다.

보내기 전에 볼 것:

- [ ] Pages 주소가 열린다
- [ ] 팀 시험(이슈 #13)에서 막힌 곳을 고쳤다
- [x] 모으는 곳을 정했다: 파일로 받기 (11/21). 아래 "일기" 줄은 그 말로 되어 있다
- [x] 코디세이 이름과 아이콘을 써도 되는지 확인했다 (11/21 이재엽: 써도 된다는 답을 받았다)

## 짧은 판

> CES 2027 준비 지도를 만들었어요 (참가자가 만든 비공식 안내예요).
> https://gamercross.github.io/ces-2027/
>
> 폰으로 열어서 홈 화면에 추가해 두면 현장에서 인터넷 없이도 열려요.
> 명함 만들기 → 분야 고르기 → 관심 회사 → 동선까지 10분이면 돼요.

## 긴 판

> **CES 2027 준비 지도 (비공식)**
> https://gamercross.github.io/ces-2027/
>
> 연수에 가는 참가자가 만든 안내예요. CES나 코디세이 운영 측의 공식 자료가 아니에요.
>
> 이렇게 써요.
> 1. 폰으로 주소를 열고 **홈 화면에 추가**해요. 한 번 열어 두면 인터넷 없이도 열려요.
> 2. **명함**을 만들어요. 깃허브와 디스코드 QR이 생겨서 현장에서 바로 보여 줄 수 있어요.
> 3. **회사**에서 보고 싶은 분야를 고르고 마음에 드는 회사에 "관심"을 눌러요.
> 4. **동선**에서 "날짜 채우기"를 누르면 날짜 · 캠퍼스 · 걷는 차례로 서요.
> 5. 현장에서는 **지도**에 가까운 부스 번호를 넣으면 내 자리와 다음 갈 곳이 보이고, 구글맵 길찾기로 넘어가요.
> 6. 본 회사마다 **일기**를 써요. 보내기를 누른 일기만 모여서, 다녀온 뒤 학생 · 취준생 · 정년 · 장년으로 나눈 한 장이 돼요.
>
> 알아 둘 것.
> - 명함 · 관심 · 동선 · 일기는 각자 폰에만 남아요. 보내기를 누른 일기만 모여요.
> - 전시사 자료는 CES 공식 전시사 검색에서 받은 것이고 첫 화면에 받은 날짜가 있어요.
> - 홀 안 부스 자리와 걷는 차례는 **짐작**이에요. 정식 배치도가 열리면 바꿔요.
> - 시간과 배지 받는 곳은 가기 전에 CES 공식 안내에서 한 번 더 확인해요.
>
> 헷갈리거나 틀린 곳이 있으면 알려 주세요.
