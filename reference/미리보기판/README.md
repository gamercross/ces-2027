# 미리 보기 판 (참고)

2026-11-19에 만든 3D 미리 보기 판(JS, three.js r147)의 본문과 자료 스크립트다. 새 판(Rust)을 만들 때 옮겨 쓸 것만 본다.

| 파일 | 옮겨 쓸 것 |
|---|---|
| `template.html` | 장소 모양(PLACES · 공식 캠퍼스 지도 좌표), 부스 번호로 자리 짐작하기, 분야 묶음 · 한글 이름, 네 태그 초안, 동선 순서, 목록 코드 · 링크 나누기 |
| `fetch-ces.mjs` | 공식 전시사 검색 요청(`X-Requested-With` 머리글 필요), 부스 → 장소 규칙 |

전시사 자료 파일은 넣지 않았다. 자료는 빌드 때 받는다.
