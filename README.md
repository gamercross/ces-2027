# 글로벌 어학연수 · CES 2027 준비 지도

화면에는 코디세이 아이콘과 "글로벌 어학연수"가 나란히 들어간다. 이 안내는 연수에 가는 참가자가 만든 **비공식** 안내다. CES(CTA)나 코디세이 운영 측의 공식 자료가 아니다.

우리 팀이 CES 2027(라스베이거스, 2027-01-06 ~ 01-09)에서 정보와 위치를 헷갈리지 않도록, 폰에서 오프라인으로도 쓰는 준비 지도다.

## 쓰는 차례

1. 처음 들어오면 **온라인 명함**을 만든다. 별명, 나(학생 · 취준생 · 정년 · 장년 중 하나), 한 줄 소개, 깃허브와 디스코드를 적으면 **QR 두 개**가 있는 명함 화면이 생긴다.
2. **주제 판**에 올해 볼 주제를 10개까지 정하고, 주제마다 볼 회사와 "누구에게 무엇이 달라지나"를 적는다 (출발 전 판).
3. 처음에 나뉜 **분야**(CES 공식 분야 49개)에서 원하는 분야를 고른다.
4. 그 분야의 **회사**들을 본다.
5. 마음에 드는 회사를 **관심**에 등록한다.
6. 관심 회사로 날짜 · 캠퍼스 · 걷는 차례의 **동선**을 짠다. **추천**(혁신상 · 한국 기업 · 내 분야, 까닭과 함께)에서 골라 담을 수 있고, **날마다 쓸 시간과 내 일정**을 넣으면 그 시간 안에 들어가게 날을 나눈다.
7. 현장에서 **내 위치와 다음 갈 곳**을 본다. 2D · 3D · 크게 보기, 구글맵 길찾기.
8. 회사마다 **일기**를 쓴다. 올해의 IT 정보를 네 태그(학생 · 취준생 · 정년 · 장년)로.
9. **보내기**를 누르면 한곳에 모이고, 네 태그로 정리한 한 장이 된다.

## 만드는 법

Rust는 두 자리에만 쓴다. 화면은 폰 먼저이고 묶는 도구 없이 그대로 올린다.

| 자리 | 무엇 |
|---|---|
| `crates/ces-data` | 빌드 때 도는 자료 도구. CES 공식 전시사 검색에서 받아(`X-Requested-With` 머리글) 부스마다 장소를 붙이고 줄여, 전시사 자료 · 찾기 색인 · 받은 날짜를 쓴다. GitHub Actions에서 돈다 |
| `crates/ces-core` | 폰에 보내는 작은 WASM 코어(의존 없음). 찾기 색인을 읽고 찾는다. 동선의 걷는 차례와 위치 맞추기는 화면 쪽(`web/route.js` · `web/locate.js`)에 둔다 (11/21에 그대로 두기로 정함) |
| `data/places.json` | 장소 자료 한 장: 홀 · 캠퍼스 모양, 부스 → 장소 규칙, 구글맵에서 쓸 이름 · 주소(Maps URLs, API 키 없음), 부스 자리가 짐작인지, GPS로 캠퍼스와 홀 근처를 고를 때 쓰는 어림 자리 |
| `data/categories.json` · `data/aliases.json` | 분야 한글 이름과 묶음, 찾기 별칭 |
| `data/topics.json` · `data/booth-spots.json` | 팀 주제를 적는 자리, 정식 배치도의 부스 자리를 적는 자리 (둘 다 지금 비어 있다) |
| `config/settings.json` | 아직 정하지 않은 것을 바꾸는 자리 (아래 표) |
| `web/` | 화면. 첫 화면은 가볍게, 찾기 자료와 코어는 쓸 때 불러온다 |
| `.github/workflows/pages.yml` | 시험 → 짓기 → 자료 받기 → 지은 것 살피기 → Pages 배포(main) |

```sh
cargo test --workspace                 # 시험
cargo run -p ces-data -- check-places  # 장소 자료 살피기
cargo run -p ces-data -- build         # 공식 사이트에서 받아 dist/data에 쓴다 (물음 110번쯤, 1분)
cargo run -p ces-data -- sort-diary --in <폴더나 파일> --out 한장.md   # 폰에서 내보낸 일기 파일들을 네 태그로 나누고 회사로 묶은 한 장으로 (예시: docs/네태그_한장_예시.md)
```

폰용 코어(`core.wasm`)는 Actions에서 짓는다(`cargo build --release -p ces-core --target wasm32-unknown-unknown`). 공식 사이트에는 하루에 한 번만 묻고, 그날 받은 답은 Actions 캐시에 두고 다시 쓴다. 새로 받으려면 Actions의 "짓기와 배포"를 손으로 돌리면서 "새로 받는다"를 켠다.

- **오프라인:** 한 번 열면 서비스 워커(`web/sw.js`)가 화면 · 코어 · 자료를 폰에 담아 다음부터 인터넷 없이 연다. 판 이름(자료 받은 날짜 + 커밋)과 담아 둘 파일 목록은 지을 때 `scripts/stamp.mjs`가 채운다. 홈 화면에 추가할 수 있다. 명함 QR도 폰에서 만든다.
- **빠르기:** 첫 화면에 쓰는 조각만 한꺼번에 받고, 찾기 자료 · 3D · 서비스 워커는 그 뒤에 받는다. `scripts/measure.mjs`가 폰 크기 · CPU 4배 느리게 · 느린 4G에서 첫 화면 시간을 잰다(쓰는 법은 파일 위쪽).
- **새 판:** 폰이 새 판을 받으면 탭 위에 "새 판이 있다 · 다시 열기"가 뜬다.
- **시간과 일정:** 날마다 쓸 시간(기본은 CES 공식 전시 시간)과 전시 밖 일정은 폰에만 남고, 작은 파일로 주고받는다. 파일의 꼴은 [docs/내일정_파일.md](docs/내일정_파일.md). 우리 일정은 이 레포에 적지 않는다.
- **현장 안내:** 급할 때 · 들어갈 때 · 도움이 필요할 때를 한곳에 모았다(`#/onsite`, 자료 `data/onsite.json`). CES 공식 '안전과 보안' · '현장 서비스' 두 쪽에서 읽은 행사장별 보안 번호(누르면 전화 앱) · 가방 규칙 · 분실물 · 응급 처치 · 접근성이고, 줄마다 출처와 읽은 날짜가 있다. 이 앱은 신고를 받지 않는다. 물어보기(`#/q`)도 이 자료와 장소 · 셔틀을 찾는다.
- **공식 앱 기준표:** CES 공식 앱의 기능 20줄이 우리 앱에 있는지 줄마다 적었다(됨 7 · 일부 10 · 없음 3, 2026-11-21): [docs/공식앱_기준표.md](docs/공식앱_기준표.md). 코드로 되는 것 · 사람과 현장이 필요한 것 · 규칙상 안 하는 것으로 나눈 표가 있다.
- **일정 고치기 · 세션 추천 · 나누기:** 내 일정을 제자리에서 고친다. 세션 일정의 "내 주제와 맞는 세션"은 내 일정 · 서로와 때가 겹치지 않게 날짜 · 시간 차례로 고르고, 세션 하나를 글로 나눈다(제목 · 때 · 공식 링크만).
- **일정 시작 알림:** 내 일정(세션 포함)이 30분 안에 시작하면 알린다. 시각은 라스베이거스 시각이고, 앱이 열려 있을 때 1분마다 확인한다. 앱이 닫혀 있을 때는 서버 없이는 못 한다.
- **명함 알림:** 종이 명함이 있는지 묻고, "명함 넣는 이벤트 있음"으로 사람이 표시한 부스가 그날 동선에 있거나 가까이에 있으면 알린다. 서버가 없어서 앱을 열 때와 내 자리가 바뀔 때만 확인하고, 알림을 못 쓰는 폰에서는 화면의 띠로 보인다 (`web/alerts.js` · `web/notify.js`).
- **따로 신청하는 곳:** CES 배지와 따로 신청 · 표 · 초대가 있어야 하는 곳, 배지만 있으면 되는 큰 일정, 자율주행 이동을 `data/separate.json`에 모았다. CES 공식 · 회사 공식 사이트만 근거로 쓰고 줄마다 출처와 확인 날짜가 있다. 2027 안내가 없는 줄은 "확인 필요"다. 첫 화면에 한 번 크게 알린다. 링크가 살아 있는지는 `cargo run -p ces-data -- check-links --in data/separate.json`이나 Actions의 "출처 링크 살피기"로 다시 본다.
- **번역은 번역 앱으로 (2026-11-22):** 영어 ↔ 한국어 번역은 파파고 · 구글 번역이 한다. "번역 앱 준비"(`#/translate`)가 출발 전에 앱 깔기와 한국어 · 영어 오프라인 팩 받기를 스토어 · 공식 도움말 링크로 안내한다. 회사 · 부스 카드와 물어볼 말의 "번역 앱 열기"는 고른 글을 복사해 두고 앱을 연다(안드로이드 크롬은 앱이 그 주소를 처리하면 앱으로, 아니면 웹 번역으로. 그 밖은 웹 번역 주소). 글은 폰의 복사 칸과 번역 앱으로만 간다. 열기 규칙은 `web/translator.js`.
- **회사마다 "대화" 칸 (2026-11-22):** 회사 줄의 "대화"(`#/talk/<회사>`)에서 듣기 · 붙여넣기 · 손으로 대화를 넣는다. 번역 앱의 대화 기록을 붙여 넣으면 줄마다 영어 / 한국어로 나누고 원문 · 번역 짝을 짓고(모양이 달라 짝을 못 지으면 그대로 한 덩어리), 상대 · 나를 바꿀 수 있다. 넣은 대화는 그 회사 일기 초안으로 이어지며 "본 것"에는 상대가 한 영어 원문 줄만 들어간다. 대화는 폰에만 남고, 일기를 파일로 내려받을 때 그 파일에 든 일기와 이어진 대화가 들어간다(모으는 곳 주소로 보내는 묶음에는 없다. 녹음은 어느 때도 가지 않는다). 나누는 규칙은 `web/talk.js`.
- **물어볼 말 · 듣기:** 부스에서 쓸 질문 묶음(`data/phrases.json`, 미리 옮겨 둔 것)을 영어로 크게 띄우고 읽어 준다. 폰이 자체 받아쓰기를 못 하면 영어 받아쓰기 모델을 누를 때 받아 이 폰에 남긴다. 받기 전에 약 45 MB와 와이파이 권장을 보인다. 모델 출처와 라이선스, 받는 크기는 [docs/물어볼말_듣기.md](docs/물어볼말_듣기.md)에 적었다. 영어 줄을 한국어로 옮기는 영한 번역 모델(OPUS-MT tc-big int8, CC-BY-4.0, 합계 약 250MB)은 지우지 않고 **깊은 설정**(`#/deep`)으로 옮겼다. 앞 화면에서는 권하지 않고, 거기서 확인을 받은 뒤 받아 켠다(기본 끔, 영어 → 한국어만). 폰 자체 번역기가 있으면 그것을 먼저 쓰고, 없을 때만 이 모델을 쓴다. 2026-11-21 데스크톱 Chromium에서 돌아가는 것을 확인했고 실제 폰(메모리 · 속도)은 확인 전이다. 자동으로 받지 않으며, 못 하는 것은 "이 폰에서는 안 됨"으로 보인다. 녹음과 들은 글은 폰에만 남는다.
- **지도:** 2D가 기본이고 3D는 지도 화면에서 누를 때 불러온다(`web/map3d.js`, 바깥 3D 엔진 없음). 홀 안 부스 자리는 부스 번호로 짐작한다(`web/spots.js`). 공식 홀 지도에서 입구와 큰 통로를 읽어 만든 길도 짐작으로 보이며, 경로 자료는 `data/indoor-paths-guess.json` 한 파일에 둔다. 위치가 튀거나 정확도가 낮으면 지도를 옮기지 않는다.

### 정하는 것

이재엽이 정하는 것은 `config/settings.json`에 있다. 바꾸려면 이 파일만 고친다. 물음과 답은 [docs/물어볼것.md](docs/물어볼것.md).

| 칸 | 지금 값 | 고를 수 있는 값 |
|---|---|---|
| `companyIntro` 공개 판의 회사 소개 | `link-only` (소개 글은 싣지 않고 공식 링크만). **11/21에 정함** | `first-sentence` (공식 소개 첫 문장 + 출처 링크) |
| `collector` 일기를 모으는 곳 | `file` (파일로 받기: 보내기를 누르면 파일이 내려온다). **11/21에 정함** | `sheet` (구글 시트 한 장. `collectorUrl`도 넣는다) |
| `collectorUrl` 보내기가 가는 주소 | `""` (비어 있으면 꺼짐: 보내기가 파일로 내려온다) | `https://`로 시작하는 주소. 넣으면 보내기가 그 주소로 일기 묶음을 POST한다 |
| `codysseyIcon` 코디세이 아이콘 | `"icon/codyssey.png"` (이름 옆에 보인다). **11/21에 넣음**: 이재엽이 운영 측에서 써도 된다는 답을 받았고, 그림은 코디세이 웹페이지의 아이콘이다 | `false` (글자만) |
| `privateOn` 비공개로 돌리는 날 | `null` | 날짜 |
