# 글로벌 어학연수 · CES 2027 준비 지도

화면에는 코디세이 아이콘과 "글로벌 어학연수"가 나란히 들어간다. 이 안내는 연수에 가는 참가자가 만든 **비공식** 안내다. CES(CTA)나 코디세이 운영 측의 공식 자료가 아니다.

우리 팀이 CES 2027(라스베이거스, 2027-01-06 ~ 01-09)에서 정보와 위치를 헷갈리지 않도록, 폰에서 오프라인으로도 쓰는 준비 지도다.

## 쓰는 차례

1. 처음 들어오면 환영 한 줄 뒤에 **온라인 명함**을 한 화면으로 만든다. 별명과 나(학생 · 취준생 · 정년 · 장년 중 하나)만 꼭 필요하고, 한 줄 소개 · 링크드인 · 깃허브 · 디스코드는 건너뛰어도 된다. 주소를 적으면 **QR**이 있는 명함이 나오고(적은 것만, 많으면 셋: 링크드인 · 깃허브 · 디스코드) "지도로"로 간다. 다시 들어오면 바로 지도이고, 설정 탭에서 QR 보기 · 명함 고치기를 한다.
2. 앱을 열면 **지도**다. 맨 위 찾기 칸에서 회사 이름 · 분야 · 부스 번호로 찾아 **관심**에 등록한다. 2D · 3D · 크게 보기, 내 위치, 구글맵 길찾기, 셔틀 · 오가는 법.
3. **갈 곳** 탭에서 관심 회사를 날짜 · 걷는 차례로 본다. 맨 위에 **다음에 갈 곳** 한 곳이 크게 있고(길 안내 · 다녀왔다), 그 아래 그다음 곳들, 다녀온 곳은 한 줄로 접힌다. **추천 회사**(혁신상 · 한국 기업 · 내 분야, 까닭과 함께)에서 골라 담을 수 있고, **내 시간과 내 일정 · 강연**을 넣으면 그 시간 안에 들어가게 "목록 고치기"가 날을 나눈다.
4. 회사마다 **일기**를 쓴다. 올해의 IT 정보를 네 태그(학생 · 취준생 · 정년 · 장년)로. 일기 탭에서 듣기 · 대화 칸 · 만난 사람으로 간다.
5. **설정**에서 명함 · 화면 색 · 알림 · 인터넷 없이 · 내보내기를 한다. 받은 일기 파일은 "모은 일기 열기"로 폰에서 바로 네 태그 한 장으로 본다.
9. **보내기**를 누르면 한곳에 모이고, 네 태그로 정리한 한 장이 된다.

## 만드는 법

Rust는 두 자리에만 쓴다. 화면은 폰 먼저이고 묶는 도구 없이 그대로 올린다.

| 자리 | 무엇 |
|---|---|
| `crates/ces-data` | 빌드 때 도는 자료 도구. CES 공식 전시사 검색에서 받아(`X-Requested-With` 머리글) 부스마다 장소를 붙이고 줄여, 전시사 자료 · 찾기 색인 · 받은 날짜를 쓴다. GitHub Actions에서 돈다 |
| `crates/ces-core` | 폰에 보내는 작은 WASM 코어(의존 없음). 찾기 색인을 읽고 찾는다. 갈 곳의 걷는 차례와 위치 맞추기는 화면 쪽(`web/route.js` · `web/locate.js`)에 둔다 (11/21에 그대로 두기로 정함) |
| `data/places.json` | 장소 자료 한 장: 홀 · 캠퍼스 모양, 부스 → 장소 규칙, 구글맵에서 쓸 이름 · 주소(Maps URLs, API 키 없음), 부스 자리가 짐작인지, GPS로 캠퍼스와 홀 근처를 고를 때 쓰는 어림 자리 |
| `data/categories.json` · `data/aliases.json` | 분야 한글 이름과 묶음, 찾기 별칭 |
| `data/topics.json` · `data/booth-spots.json` | 팀 주제를 적는 자리, 정식 배치도의 부스 자리를 적는 자리 (둘 다 지금 비어 있다) |
| `config/settings.json` | 아직 정하지 않은 것을 바꾸는 자리 (아래 표) |
| `web/` | 화면. 첫 화면(지도)은 가볍게, 찾기 자료와 코어는 쓸 때 불러온다 |
| `.github/workflows/pages.yml` | 시험 → 짓기 → 자료 받기 → 지은 것 살피기 → Pages 배포(main) |

```sh
cargo test --workspace                 # 시험
cargo run -p ces-data -- check-places  # 장소 자료 살피기
cargo run -p ces-data -- build         # 공식 사이트에서 받아 dist/data에 쓴다 (물음 110번쯤, 1분)
cargo run -p ces-data -- sort-diary --in <폴더나 파일> --out 한장.md   # 폰에서 내보낸 일기 파일들을 네 태그로 나누고 회사로 묶은 한 장으로 (예시: docs/네태그_한장_예시.md)
```

폰용 코어(`core.wasm`)는 Actions에서 짓는다(`cargo build --release -p ces-core --target wasm32-unknown-unknown`). 공식 사이트에는 하루에 한 번만 묻고, 그날 받은 답은 Actions 캐시에 두고 다시 쓴다. 새로 받으려면 Actions의 "짓기와 배포"를 손으로 돌리면서 "새로 받는다"를 켠다.

- **오프라인:** 한 번 열면 서비스 워커(`web/sw.js`)가 화면 · 코어 · 자료를 폰에 담아 다음부터 인터넷 없이 연다. 판 이름(자료 받은 날짜 + 커밋)과 담아 둘 파일 목록은 지을 때 `scripts/stamp.mjs`가 채운다. 홈 화면에 추가할 수 있다. 명함 QR도 폰에서 만든다.
- **빠르기:** 첫 화면(지도)에 쓰는 조각만 한꺼번에 받고, 찾기 자료 · 3D · 서비스 워커는 그 뒤에 받는다. `scripts/measure.mjs`가 폰 크기 · CPU 4배 느리게 · 느린 4G에서 첫 화면 시간을 잰다(쓰는 법은 파일 위쪽).
- **아래 탭은 넷 (11/22, 다시 짓기 2단계):** 지도 · 갈 곳 · 일기 · 설정(둘째 탭은 11/23에 "동선"에서 "갈 곳"으로 이름을 바꿨다). 앱을 열면 지도(명함이 없으면 명함부터). 회사 찾기는 지도 위 찾기 칸, 다음에 갈 곳 · 관심 · 추천 회사(`#/rec`) · 내 시간(`#/days`) · 강연 일정(`#/sessions`)은 갈 곳, 셔틀 · 오가는 법(`#/transit`)은 지도, 듣기 · 대화 칸 · 만난 사람은 일기, 명함 · 화면 색 · 알림 · 인터넷 없이 · 내보내기는 설정에 있다. 첫 화면 · 회사 탭 · 따로 신청 · 현장 안내 · 물어보기 · 주제 판 · 알아둘 것은 지웠다. 화면마다 제목 한 줄 + 꼭 필요한 한두 줄, 긴 목록은 칩 한 줄로 한 번에 한 묶음. 화면 색은 자동(폰 설정을 따름) · 밝게 · 어둡게(`web/theme.js` · `web/tokens.css`), 탭마다 강조색이 하나다. 기준은 [design.md](design.md), 탭 넷 사진은 `docs/screens/70 ~ 73`.
- **전시사 목록 (11/23, R53):** 지도 칩 줄 맨 앞 "목록"(`#/list`). 공식 앱의 전시사 A–Z 목록처럼 이름순(위에 붙은 글자 줄) · 부스순으로 보고 혁신상 · 한국 · 위치 · 나라 · 분야로 거른다. 줄을 누르면 지도에서 카드, 줄의 "관심"으로 바로 담는다.
- **세션 찾기 · 거르기 (11/23, R54):** 세션 일정의 날짜 칩 아래 거르기 칩(기조연설 · 생중계 · 내 일정 · 분야). 지도 찾기 칸에 영어 낱말을 넣으면 세션도 두 줄까지 나온다.
- **갈 곳 (11/23, R55, 안 1):** 동선 탭을 "갈 곳"으로 다시 지었다. 날짜 한 줄(‹ 1월 6일 (수) · 남은 4곳 ›, 남은 곳 수는 11/24에 더했다) → 다음에 갈 곳 한 곳 크게(길 안내 · 다녀왔다) → 그다음 곳들 → 다녀온 곳 접기 → "목록 고치기 · 지도에서 보기". "다녀왔다"를 누르면 "일기 쓰기"가 6초 뜬다. 1/5(전시 전날)에는 회사를 넣지 못하고 내 일정만 보인다. 문서 · 표 파일로 내보내기와 시간 · 일정 파일은 설정으로 옮겼다. 기준은 [docs/디자인/동선_쉽게_안.md](docs/디자인/동선_쉽게_안.md), 사진은 `docs/screens/190` ~ `198`.
- **새 판:** 폰이 새 판을 받아 두면 탭 위에 "새 판이 있다 · 다시 열기"가 뜬다. 누르기 전에는 앱을 껐다 켜도 쓰던 판 그대로이고, 누를 때만 새 판으로 바뀐다(인터넷이 없어도 된다).
- **시간과 일정:** 날마다 쓸 시간(기본은 CES 공식 전시 시간)과 전시 밖 일정은 폰에만 남고, 작은 파일로 주고받는다. 파일의 꼴은 [docs/내일정_파일.md](docs/내일정_파일.md). 우리 일정은 이 레포에 적지 않는다.
- **공식 앱 기준표:** CES 공식 앱의 기능이 우리 앱에 있는지 줄마다 적었다(2026-11-22에 앱 살펴보기 7줄과 웹 플래너 7줄을 더해 34줄, 2026-11-23 전시사 목록(R53) · 세션 거르기(R54) 뒤 **됨 10 · 일부 14 · 없음 10**): [docs/공식앱_기준표.md](docs/공식앱_기준표.md). 코드로 되는 것 · 사람과 현장이 필요한 것 · 규칙상 안 하는 것으로 나눈 표가 있다.
- **오프라인 점검 (참고, 2026-11-24):** [docs/참고/오프라인-점검.md](docs/참고/오프라인-점검.md)(인터넷이 없을 때 기능마다 되는지 · 자료가 사라질 위험 · 출발 전 할 일 · 고칠 안). 끊고 써 보는 시험은 `node tests/offline.mjs <지은 dist>`.
- **공식 앱 · 계정 · 웹 플래너 살펴보기 (참고, 2026-11-22):** [docs/참고/ces2026-앱-살펴보기.md](docs/참고/ces2026-앱-살펴보기.md)(폰 앱 약 30화면과 디자인 관찰) · [docs/참고/ces2027-계정과-웹플래너.md](docs/참고/ces2027-계정과-웹플래너.md)(CES 계정 · 로그인해서 본 웹 플래너 · 우리 앱에 더할 것). 더할 것 넷은 요구사항.md의 R46 ~ R49 **(안)** 으로 올렸고 아직 짓지 않았다.
- **일정 고치기 · 세션 추천 · 나누기:** 내 일정을 제자리에서 고친다. 세션 일정의 "내 주제와 맞는 세션"은 내 일정 · 서로와 때가 겹치지 않게 날짜 · 시간 차례로 고르고, 세션 하나를 글로 나눈다(제목 · 때 · 공식 링크만).
- **일정 시작 알림:** 내 일정(세션 포함)이 30분 안에 시작하면 알린다. 시각은 라스베이거스 시각이고, 앱이 열려 있을 때 1분마다 확인한다. 앱이 닫혀 있을 때는 서버 없이는 못 한다.
- **명함 알림:** 종이 명함이 있는지는 설정의 "종이 명함" 줄에서 답하고, "명함 넣는 이벤트 있음"으로 사람이 표시한 부스가 그날 갈 곳에 있거나 가까이에 있으면 알린다. 서버가 없어서 앱을 열 때와 내 자리가 바뀔 때만 확인하고, 알림을 못 쓰는 폰에서는 화면의 띠로 보인다 (`web/alerts.js` · `web/notify.js`).
- **번역은 지웠다 (2026-11-22):** 이재엽이 방향을 다시 정했다("필요한 내용들은 일기 · 지도 · 동선 그리고 설정. 번역하는 건 지워 줘"). 번역 앱 준비 · 번역 앱 열기 · 물어볼 말 · 깊은 설정과 폰 안 영한 번역 모델 · 듣기 줄 옆 한국어 옮기기를 지웠다. 이 앱은 번역하지 않는다. 앞으로의 차례는 [작업.md](작업.md)의 "다시 짓기 (11/22)".
- **회사마다 "대화" 칸 (2026-11-22):** 회사 줄의 "대화"(`#/talk/<회사>`)에서 듣기 · 붙여넣기 · 손으로 대화를 넣는다. 복사한 대화를 붙여 넣으면 줄마다 영어 / 한국어로 나누고 위 줄 · 아래 줄 짝을 짓고(모양이 달라 짝을 못 지으면 그대로 한 덩어리), 상대 · 나를 바꿀 수 있다. 넣은 대화는 그 회사 일기 초안으로 이어지며 "본 것"에는 상대가 한 영어 원문 줄만 들어간다. 대화는 폰에만 남고, 일기를 파일로 내려받을 때 그 파일에 든 일기와 이어진 대화가 들어간다(모으는 곳 주소로 보내는 묶음에는 없다. 녹음은 어느 때도 가지 않는다). 나누는 규칙은 `web/talk.js`.
- **듣기:** 부스에서 상대의 영어를 받아 적는다. 녹음을 알리는 말은 영어로 크게 띄우고 읽어 준다. 폰이 자체 받아쓰기를 못 하면 영어 받아쓰기 모델을 누를 때 받아 이 폰에 남긴다. 받기 전에 약 45 MB와 와이파이 권장을 보인다. 모델 출처와 라이선스, 받는 크기는 [docs/물어볼말_듣기.md](docs/물어볼말_듣기.md)에 적었다. 못 하는 것은 "이 폰에서는 안 됨"으로 보인다. 녹음과 들은 글은 폰에만 남는다.
- **길 안내 (11/22):** 카드의 "길 안내 시작" · 갈 곳 탭의 "길 안내" · 지도 아래 "다음 갈 곳" 띠(고른 날의 회사만)로 시작한다. 내 위치에서 목적지까지 선과 남은 거리 · 걸어서 몇 분 · 방향이 아래 띠에 나오고(`web/nav.js`), 걸으면 지도가 따라온다(손으로 끌면 멈춤). 같은 홀이면 홀 입구와 큰 통로를 따라가는 짐작 길, 다른 캠퍼스면 구글맵 길찾기. 거리와 시간은 부스 자리가 짐작이라 짐작이다.
- **지도 (4단계, 11/22):** 2D가 기본이고 손가락으로 크게 · 작게(두 손가락 벌리기 · 두 번 톡), 한 손가락으로 끌 수 있다(`web/mapgesture.js`, 프레임마다 한 번만 그린다). 확대 단계는 캠퍼스 셋 → 홀 → 부스 셋이고 확대할수록 홀 이름 → 큰 회사 · 관심 회사 이름 → 부스 번호와 회사 이름이 보인다(글자 13px 이상, 겹치면 숨김, `web/mapmath.js`). 위에 찾기 칸(`web/mapfind.js`)과 홀 칩 한 줄, 회사를 누르면 아래에서 올라오는 큰 카드(`web/mapsheet.js`), 오늘 갈 곳의 회사에 번호 점과 이은 선이 있다. 3D는 지도 위 단추를 누를 때 불러온다(`web/map3d.js`, 바깥 3D 엔진 없음). 3D에도 그 날 차례 선 · 갈 곳 번호 · 길 안내 선과 다음에 갈 곳 이름을 2D와 같이 그리고, 누르면 손가락 아래에 있는 것(부스 · 홀 · 멀리 볼 때의 캠퍼스)이 열린다. 전시사 자료는 지을 때 홀마다 나눠(`scripts/split-halls.mjs` → `data/halls/<장소>.json`) 홀로 가까이 갈 때 그 홀의 것만 받는다. 홀 안 부스 자리는 부스 번호로 짐작한다(`web/spots.js`, 카드에 "자리 짐작"). 공식 홀 지도에서 입구와 큰 통로를 읽어 만든 길도 짐작으로 보이며, 경로 자료는 `data/indoor-paths-guess.json` 한 파일에 둔다. 위치가 튀거나 정확도가 낮으면 지도를 옮기지 않는다.
- **다른 곳에서 가져온 것 · 가져올 것:** [docs/가져올것.md](docs/가져올것.md). **남은 일의 준비:** 정식 배치도([docs/정식배치도_넣는법.md](docs/정식배치도_넣는법.md)) · 모으는 곳([docs/모으는곳_준비.md](docs/모으는곳_준비.md)) · 현장 하루([docs/현장_하루.md](docs/현장_하루.md)) · 비공개([docs/비공개_차례.md](docs/비공개_차례.md)). **정할 것:** [docs/물어볼것.md](docs/물어볼것.md).

### 정하는 것

이재엽이 정하는 것은 `config/settings.json`에 있다. 바꾸려면 이 파일만 고친다. 물음과 답은 [docs/물어볼것.md](docs/물어볼것.md).

| 칸 | 지금 값 | 고를 수 있는 값 |
|---|---|---|
| `companyIntro` 공개 판의 회사 소개 | `link-only` (소개 글은 싣지 않고 공식 링크만). **11/21에 정함** | `first-sentence` (공식 소개 첫 문장 + 출처 링크) |
| `collector` 일기를 모으는 곳 | `file` (파일로 받기: 보내기를 누르면 파일이 내려온다). **11/21에 정함** | `sheet` (구글 시트 한 장. `collectorUrl`도 넣는다) |
| `collectorUrl` 보내기가 가는 주소 | `""` (비어 있으면 꺼짐: 보내기가 파일로 내려온다) | `https://`로 시작하는 주소. 넣으면 보내기가 그 주소로 일기 묶음을 POST한다 |
| `codysseyIcon` 코디세이 아이콘 | `"icon/codyssey.png"` (이름 옆에 보인다). **11/21에 넣음**: 이재엽이 운영 측에서 써도 된다는 답을 받았고, 그림은 코디세이 웹페이지의 아이콘이다 | `false` (글자만) |
| `privateOn` 비공개로 돌리는 날 | `null` | 날짜 |
| `speech` 받아쓰기를 어디서 하나 (고르기 전의 기본값) | `on-device` (폰 안에서만. 소리와 글이 폰 밖으로 나가지 않는다. 안 되는 폰이 많다). **11/21에 정함: 두 길을 다 두고 쓰는 사람이 화면에서 고른다. 기본은 폰 안에서만** | `device-service` (폰의 음성 인식 서비스. 인터넷이 있어야 하고 소리가 구글 · 애플로 간다. 화면에서 처음 고를 때 한 번 확인받는다) |
| `companyImage` 회사 로고 단추 | `true` (회사 카드에 "로고 보기"가 생기고 누르면 공식 새 창을 연다). **11/21에 켬으로 정함** | `false` (로고 자료와 새 창 단추를 묻지 않는다) |
| `companyImage` 회사 로고 단추 | `false` (끄면 회사 카드에 로고를 묻지 않는다). 공식 전시사 자료에 있는 로고는 누를 때만 새 창으로 연다 | `true` (회사 카드에 "로고 보기"를 보인다) |
