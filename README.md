| `codysseyIcon` 코디세이 아이콘 | `false` (글자만) | 그림 주소 (예: `"icon/codyssey.png"`, 운영팀 확인 뒤 그림을 `web/icon/`에 넣는다) || 프리 프로토타입: 기능을 만든다 | ~12/6 | 하는 중 ([작업.md](작업.md)) |# 글로벌 어학연수 · CES 2027 준비 지도

화면에는 코디세이 아이콘과 "글로벌 어학연수"가 나란히 들어간다. 이 안내는 연수에 가는 참가자가 만든 **비공식** 안내다. CES(CTA)나 코디세이 운영 측의 공식 자료가 아니다.

우리 팀이 CES 2027(라스베이거스, 2027-01-06 ~ 01-09)에서 정보와 위치를 헷갈리지 않도록, 폰에서 오프라인으로도 쓰는 준비 지도다.

## 쓰는 차례

1. 처음 들어오면 **온라인 명함**을 만든다. 별명, 나(학생 · 취준생 · 정년 · 장년 중 하나), 한 줄 소개, 깃허브와 디스코드를 적으면 **QR 두 개**가 있는 명함 화면이 생긴다.
2. 처음에 나뉜 **분야**(CES 공식 분야 49개)에서 원하는 분야를 고른다.
3. 그 분야의 **회사**들을 본다.
4. 마음에 드는 회사를 **관심**에 등록한다.
5. 관심 회사로 날짜 · 캠퍼스 · 걷는 차례의 **동선**을 짠다.
6. 현장에서 **내 위치와 다음 갈 곳**을 본다. 2D · 3D · 크게 보기, 구글맵 길찾기.
7. 회사마다 **일기**를 쓴다. 올해의 IT 정보를 네 태그(학생 · 취준생 · 정년 · 장년)로.
8. **보내기**를 누르면 한곳에 모이고, 네 태그로 정리한 한 장이 된다.

## 만드는 법

Rust는 두 자리에만 쓴다. 화면은 폰 먼저이고 묶는 도구 없이 그대로 올린다.

| 자리 | 무엇 |
|---|---|
| `crates/ces-data` | 빌드 때 도는 자료 도구. CES 공식 전시사 검색에서 받아(`X-Requested-With` 머리글) 부스마다 장소를 붙이고 줄여, 전시사 자료 · 찾기 색인 · 받은 날짜를 쓴다. GitHub Actions에서 돈다 |
| `crates/ces-core` | 폰에 보내는 작은 WASM 코어(의존 없음). 찾기 색인을 읽고 찾는다. 동선 · 위치 맞추기는 뒤 세션에서 더한다 |
| `data/places.json` | 장소 자료 한 장: 홀 · 캠퍼스 모양, 부스 → 장소 규칙, 구글맵에서 쓸 이름 · 주소(Maps URLs, API 키 없음), 부스 자리가 짐작인지, GPS로 캠퍼스와 홀 근처를 고를 때 쓰는 어림 자리 |
| `data/categories.json` · `data/aliases.json` | 분야 한글 이름과 묶음, 찾기 별칭 |
| `config/settings.json` | 아직 정하지 않은 것을 바꾸는 자리 (아래 표) |
| `web/` | 화면. 첫 화면은 가볍게, 찾기 자료와 코어는 쓸 때 불러온다 |
| `.github/workflows/pages.yml` | 시험 → 짓기 → 자료 받기 → 지은 것 살피기 → Pages 배포(main) |

```sh
cargo test --workspace                 # 시험
cargo run -p ces-data -- check-places  # 장소 자료 살피기
cargo run -p ces-data -- build         # 공식 사이트에서 받아 dist/data에 쓴다 (물음 110번쯤, 1분)
cargo run -p ces-data -- sort-diary --in <폴더나 파일> --out 한장.md   # 폰에서 내보낸 일기 파일들을 네 태그로 나누고 회사로 묶은 한 장으로 (예시: docs/네태그_한장_예시.md)
```

폰용 코어(`core.wasm`)는 Actions에서 짓는다(`cargo build --release -p ces-core --target wasm32-unknown-unknown`). 공식 사이트에는 하루에 한 번만 묻고, 그날 받은 답은 Actions 캐시에 두고 다시 쓴다. 새로 받으려면 Actions의 "짓기와 배포"를 손으로 돌리면서 "새로 받는다"를 켠다.

- **오프라인:** 한 번 열면 서비스 워커(`web/sw.js`)가 화면 · 코어 · 자료를 폰에 담아 다음부터 인터넷 없이 연다. 판 이름(자료 받은 날짜 + 커밋)과 담아 둘 파일 목록은 지을 때 `scripts/stamp.mjs`가 채운다. 홈 화면에 추가할 수 있다. 명함 QR도 폰에서 만든다.
- **빠르기:** 첫 화면에 쓰는 조각만 한꺼번에 받고, 찾기 자료 · 3D · 서비스 워커는 그 뒤에 받는다. `scripts/measure.mjs`가 폰 크기 · CPU 4배 느리게 · 느린 4G에서 첫 화면 시간을 잰다(쓰는 법은 파일 위쪽).
- **새 판:** 폰이 새 판을 받으면 탭 위에 "새 판이 있다 · 다시 열기"가 뜬다.
- **지도:** 2D가 기본이고 3D는 지도 화면에서 누를 때 불러온다(`web/map3d.js`, 바깥 3D 엔진 없음). 홀 안 부스 자리는 부스 번호로 짐작한다(`web/spots.js`).
- 참고: [`reference/미리보기판/`](reference/미리보기판/)은 11/19에 만든 3D 미리 보기 판(JS)의 본문과 자료 스크립트다.

### 아직 정하지 않은 것

`config/settings.json`의 값은 임시다. 이재엽이 정하면 이 파일만 고친다.

| 칸 | 지금 값 | 고를 수 있는 값 |
|---|---|---|
| `companyIntro` 공개 판의 회사 소개 | `link-only` (소개 글은 싣지 않고 공식 링크만) | `first-sentence` (공식 소개 첫 문장 + 출처 링크) |
| `collector` 일기를 모으는 곳 | `undecided` | 정하면 적는다 (구글 시트 한 장 / 파일로 받기) |
| `collectorUrl` 보내기가 가는 주소 | `""` (비어 있으면 꺼짐: 보내기가 파일로 내려온다) | `https://`로 시작하는 주소. 넣으면 보내기가 그 주소로 일기 묶음을 POST한다 |
| `codysseyIcon` 코디세이 아이콘 | `false` (글자만) | `true` (운영팀 확인 뒤) |
| `privateOn` 비공개로 돌리는 날 | `null` | 날짜 |

## 자료

- 전시사: CES 공식 전시사 검색 exhibitors.ces.tech. 받은 날짜를 화면에 보인다.
- 홀 위치: CES 공식 캠퍼스 지도(2026-09-29판). 홀 안 부스 자리는 정식 배치도가 열리기 전까지 부스 번호로 짐작한다.
- 구글맵 주소: CES 공식 자료에는 거리 주소가 없어, 장소가 스스로 밝힌 주소를 적고 확인한 날을 남겼다 (`data/places.json`의 `venues`).
- 자세한 출처와 날짜: [data/출처.md](data/출처.md). 네 태그 규칙 초안: [data/네태그_규칙.md](data/네태그_규칙.md). 기록 틀: [docs/기록틀.md](docs/기록틀.md).

## 지키는 것

- 연수 일정표 · 참가자 이름 목록 · 서류 · 연락처는 넣지 않는다.
- API 키 · 토큰을 넣지 않는다.
- 명함 · 관심 · 동선 · 일기는 각자 폰에 남는다. 명함 QR은 보여 줄 때만 상대가 읽고, 일기는 보내기를 누를 때만 모인다.
